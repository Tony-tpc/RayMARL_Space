## 1. 实施范围

环境按[完整规格](modeling_complete_zh.md)落实 UC 六维物理动作、Consumer 四维物理动作、联合合法域、两层三步出清、固定充电与主动弃电、额度内实际购电和放电、真实回补 FIFO、公告供给考核及全部费用。式（1）—（29）的生产函数和验证位置见[对应表](formula_implementation_map_zh.md)。式（30）保留为原论文引用，未加入 v9 奖励。

| 接口与行为 | 当前实现 |
|---|---|
| 行动输入 | dataclass 或物理向量；旧五维 UC、旧报价字段和旧快照明确拒绝 |
| 可行动作生成 | 独立纯 NumPy 函数，由调用者显式调用；环境不调用映射覆盖输入 |
| 市场 | 必要层先于提前回补层；每层 DER PAB→UC 比例→DER 原报价补配；同价比例分配 |
| 消费任务 | 到期预留、柔性共享、队列容量、最早截止及同截止 FIFO；实际回补才扣账 |
| 物理 | 固定充电、固定主动弃电、公告额度内执行；无备用、UC 竞价或自放电 |
| 信息 | UC H+20 聚合输入，Consumer H+24 本人输入；完整诊断通过独立接口读取 |
| 时序 | UC 只冻结公告；Consumer 齐备才推进物理期；候选检查后原子提交 |
| 生命周期 | 真终止一次终端结算；连续运行保留状态，耗尽明确报错，数据显式追加 |
| 可复算记录 | 入期状态、双方观测、条件边界、原行动、全部中间账本、稳定任务 ID |
| 配置与来源 | 可配置分时时窗、个人系数和容量、数据元信息、完整日历及来源哈希 |

UC 公共反馈不包含逐户任务或成本。聚合输入本身不构成形式化隐私协议；模型仍按聚合机制设计。

## 4. 实现审查中发现并修复的问题

| 问题 | 修复及回归证据 |
|---|---|
| 满额放电产生机器精度负 SOC | 仅归一化容差内的边界状态并记录残差；原物理行动保持 |
| 完成任务残留浮点尾差 | 按实际减法精度处理已完成余量；真实微小未服务任务仍保留 |
| 可行映射插值越过报价端点一个浮点单位 | 在纯映射内部固定端点；直接提交的非法物理动作仍报错 |
| 可变返回对象影响内部历史 / 快照 | 独立复制、不可变状态及候选完整性校验 |
| 相同绝对时刻而 UTC 偏移不同 | 构造、恢复、CSV 和追加均保持同一本地价表日历 |
| 快照字典乱序导致最近记录错误 | 按物理期排序恢复，终端公告与历史一致 |
| 分时时窗硬编码、任务缺少稳定 ID | 时窗配置化；确定性任务 ID 在部分回补和恢复后保持 |
| 记录缺少当期观测和条件边界 | 保存完整决策输入与容量减少分解，便于独立复算 |
| 连续数据耗尽的载体观测被误当可 bootstrap | 明确标记不可用，要求追加连续数据后读取有效下一观测 |

预检失败和人工中断的运行目录保留用于定位修复；它们没有计入本报告正式完成量。正式运行从冻结后的统一源码开始，全部批次通过，源码哈希在运行结束时保持一致。正式运行曾因 Windows 进度文件共享锁中断协调器，之后从同来源、已原子保存的成功批次继续；该文件访问异常与数值检查失败分开记录，详见运行目录的 `resume_history.json`。

## 5. 经济结果与剩余模型问题

以下单期算例均使用 15 分钟步长；功率乘 0.25 h 后按电量结算，奖励中的非现金考核使用元等值。

| 项目 | 当前生产验证与结论 |
|---|---|
| U01 服务成本区间 | 固定 1 kWh、零售价 0.40、PG 价 1.70 时服务奖励 −1.30，限供奖励 −3.00。当前赔偿 1.00 加考核 2.00 的单期固定请求临界 PG 价为 3.40；阈值两侧已测试。 |
| U02 来源替代 | 直接 DER 成交收益 0.30；弃 DER 后 PG/UC 供电收益 0.60，消费者支付 0.30→0.90。完整服务仍可发生来源替代，按原公式保留。 |
| U03 公告责任 | 文档无补偿诱导削减例的旧规则对照值为 0；当前生产主系数 2.00 下为 −2.00，正常供给为 −0.25。低考核配正 DR 估值仍可恢复限供优势，测试保留此参数边界。 |
| A01 已有减载认领 | 固定净减载 4 kW，付费采购不新增响应，却使奖励 −2.00→−0.50；付费量与额外响应须分列。 |
| A02 到期额外预留 | 基线 4、到期回补 2，消费者削减 4、请求回补 2，实际供给与付费 DR 均为 2 kW。全部请求完成后仍产生 6−2−2=2 kW 考核缺口、1.00 元等值成本；原口径保留。 |
| A03 公告额度平坦区 | 固定 2 kW 成交，PG 额度 4→8 不改变实际进口和奖励；闲置额度分别记录。 |
| A04 物理能力与自主调度 | 相同零公告可来自零资源或主动保留。记录最大物理供给及 PG 保留、放电保留、充电分流、主动弃电；这些是容量减少量，不直接等同于可相加的缺口罚款。 |
| U04 基线与跨期 | 两期移出—回补验证总电量守恒；终端成本、SOC 和月账本按规格更新。真实基线、因果响应、终端参数仍需数据标定。 |

主合成配置沿用 H=T=96 且采用有限期，因此依照 `t+H <= T-1`，本回合不会新移出任务。研究移峰时需使用 H<T 的有限场景或连续模式；本次测试同时覆盖这些设置。这里保留文档行动域和原配置，未通过改变执行规则打开移出。

本轮验证证明已测场景中的实现一致性和数值闭合。学习收敛、消费者最佳响应、UC 重新适应与 SNE 属于后续策略实验。
