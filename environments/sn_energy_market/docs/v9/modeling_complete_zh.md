# 第一部分　系统与共同定义

## 1. 研究对象与决策关系

### 1.1 社区能源系统

考虑由一个 UC 和 $N$ 个消费者组成的社区。UC 管理外部电网 PG 进口接口、共享 DER 和共享 ESS。消费者使用社区提供的能源，并通过削减和移峰调整自身负荷。

本模型采用单母线有功聚合表示，研究资源供给、负荷调节、能量存量和经济支付的相互作用。每个时段的 DER 可用出力为 $p^{DER}$，PG 进口物理上限为 $\bar p^{PG}$，ESS 入期电量为 $E$。UC 自有 DER 的现金运行成本由 $k_R$ 描述。

### 1.2 UC 的资源配置问题

UC 决定本期向市场开放多少 PG 和储能能力，投入多少资源充电，退出多少 DER，以及愿意购买多少 DR。不同决策改变当前售电结构和下一期资源状态：扩大 PG 额度提高供给空间；放电替代当前购电并消耗电池；充电积累未来电量；主动弃电减少当期 DER 供给；DR 采购改变消费者的调整收益。

UC 的优化对象是这些资源和激励选择产生的长期收益。因此，当前市场容量与未来 SOC 同时进入上层决策。

### 1.3 消费者的响应与竞争

消费者最小化自身长期用电成本。其成本由电费、DR 收入、服务赔偿、调整不适、等待和失供代价构成。消费者可以削减本期需求，也可以把用电移到后续时段，或者提前执行历史任务。

DER 按报价分配稀缺资源，同价订单按量分配。UC 供电按公告零售价收费，在同一需求层内按剩余请求比例分配。消费者之间通过 DER 排序、共同供给容量和 DR 付款池形成战略联系。

### 1.4 决定权与执行流程

| 参与者 / 模块 | 输入 | 决定或计算的量 |
|---|---|---|
| UC Actor | 资源、电池、价格和历史状态 | 六维资源与激励行动 |
| 消费者 Actor | 本人状态与 UC 公告 | 削减、移峰、DER 比例和报价 |
| 市场 | 分层请求、报价与公告容量 | 每户 DER、UC 成交功率 |
| 物理模块 | UC 决策与市场成交 | 实际 PG、ESS、弃电及期末 SOC |
| 服务与 FIFO | 原生需求、任务与成交 | 原生服务、任务完成和剩余债务 |
| 结算与奖励 | 服务、交易与价格 | 双边资金、经营成本和各方回报 |

```text
冻结外生输入与入期状态
→ UC 六维行动与容量公告
→ 消费者同时生成四维行动
→ 必要需求出清 → 可提前回补出清
→ 资源执行 → 原生服务与 FIFO 更新
→ DR 采购 → 现金与成本结算
→ 奖励及终端计算 → 校验与一次提交
```

UC 和消费者各行动一次。市场的分层计算属于同一轮出清，联合决策通过这条执行链推进一个物理时段。

## 2. 时间、单位与状态

### 2.1 离散时间和物理单位

离散时段为 $t=0,1,\ldots,T-1$，步长 $\Delta t$ 的单位为 h。主要合成场景取 $\Delta t=0.25$ h，即每天 96 个时段。$t,T,H$ 记录时段序号或个数，相应物理时长由时段个数乘 $\Delta t$ 得到。本期功率按时段平均功率理解，功率乘以步长得到本期电量，再乘电量单价得到费用。

| 类型 | 单位 | 典型变量 |
|---|---|---|
| 功率 | kW | 请求、供给额度、充放电、弃电、DR 上限 |
| 电量 | kWh | 电池存量 $E$、FIFO 任务、月累计；$E$ 采用电量口径 |
| 电量单价 / 单位电量估值 | 元/kWh | 零售价、报价、采购价、补偿、失供与终端估值 |
| 电量持有成本率 | 元/(kWh·h) | 消费者任务等待与逾期持续成本 |
| 每次期末考核的单位电量系数 | 元/kWh，逐次考核 | UC 到期残留量考核 |
| 现金金额 | 元 | 电费、补偿、赔偿、外部支出、现金利润 |
| 效用金额 | 元等值 | 退化与机会成本、主观不适、服务考核、奖励 |

成本使用四种计量依据：按电量计价的功率项乘一次 $\Delta t$；按持续时长计价的电量存量项也乘一次 $\Delta t$；每次考核或终端结算直接对已知电量计价；已经形成的金额直接加减。第 2.8 节按这一规则核对全部成本与奖励。

### 2.2 当期外生输入

消费者输入为原始基线 $p_i^{base}$、刚性负荷 $p_i^{rigid}$ 和柔性能力 $\bar p_i^{flex}$；供给输入为 $p^{DER},\bar p^{PG},w$；事件输入为 $\chi,T^{DR}$。输入在行动前冻结，整轮公告、出清和结算使用同一份数据。

基础场景提供当期可用资源和采购价格。预测场景应把预测值、实现值及误差发生时点一起写入数据契约。参数满足 $0\le p_i^{rigid}\le p_i^{base}$、非负容量和有限数值，效率在 $(0,1]$，$\Delta t>0$、$\bar p_i^{flex}\ge0$。

### 2.3 持久状态

| 状态 | 含义 | 更新来源 |
|---|---|---|
| $E$ | 电池入期电量 | 上期实际充放电 |
| $M_i$ | 当月累计 UC 购电量 | 上期 UC 成交电量 |
| $\mathcal Q_i$ | 任务 ID、创建期、截止期、剩余电量 | 新移出与实际回补 |
| $B_i$ | 任务总剩余量 | FIFO 列表求和 |
| $D_i^{due}$ | 当前到期及逾期量 | 截止期不晚于 $t$ 的任务求和 |
| 阶段与随机状态 | 当前行动者、数据索引、随机数状态 | 执行编排 |
| 历史结果 | 服务、支付、DR 和额度使用 | 上期结算 |

队列上限为 $\bar B_i$，固定延期为 $H\ge1$ 个时段。有限期剩余期数为 $T-t$；连续模式使用 −1 表示开放时域。

### 2.4 两个决策时刻

UC 决策前的状态记为 $s_t^U$。UC 行动后，状态增加本轮资源公告，形成消费者决策前状态 $s_t^C$。物理期末统一更新电池、任务、月账本和时钟。

这个安排使消费者使用当期 UC 条件行动，同时使 Critic 能按各自决策时刻估计价值。下一消费者决策状态由下一轮 UC 公告形成，轨迹通过物理时段 ID 对齐。

### 2.5 统一功率记号与代号

功率统一用 $p$ 表示，右上角说明用途；$\bar p$ 表示设备或配置上限，$i$ 表示消费者。$B,D,V,E,M,q$ 保留为电量或电量状态，$T,b,w$ 为价格。成本、收益、利润与转账金额统一用 $C^{\text{代号}}$ 或 $C_i^{\text{代号}}$；$R_j$ 为强化学习奖励，$J_j$ 为长期目标，$\pi$ 为策略。

| 代号 | 功率含义 |
|---|---|
| $p^{DER}$、$\bar p^{PG}$ | 当期 DER 可用出力、PG 进口物理上限 |
| $p^{PG,offer}$、$p^{PG,exec}$ | UC 公告的 PG 额度、实际进口 |
| $p^{ch,DER}$、$p^{ch,PG}$ | DER、PG 两路确定充电 |
| $p^{dis,offer}$、$p^{dis,exec}$、$p^{dis,avail}$ | 放电额度、实际放电、入期可用放电能力 |
| $p^{curt}$、$p^{unsold}$、$p^{spill}$ | 主动弃电、未售弃电、合计弃电 |
| $p^{DER,cap}$、$p^{UC,cap}$ | 两池公告可售容量 |
| $p^{DER,sold}$、$p^{UC,sold}$ | 两池全体成交合计 |
| $p_i^{base}$、$p_i^{rigid}$、$\bar p_i^{flex}$ | 本户基线、刚性负荷、共享调节上限 |
| $p_i^{cut}$、$p_i^{shift}$、$p_i^{due}$ | 削减动作、带符号移峰动作、最低到期回补请求 |
| $p_i^{native}$、$p_i^{req}$、$p_i^{nec}$ | 原生需求、总请求、必要层请求 |
| $p_i^{DER}$、$p_i^{UC}$、$p_i^{serve}$ | 两来源成交、本户总服务 |
| $p_i^{lost}$、$p_i^{repay}$ | 原生失供、实际回补 |
| $p_i^{DR}$、$p^{DR,net}$ | 个人有符号减载、全体净减载 |
| $p^{DR,cap}$ | UC 的可补偿采购功率上限 |

其中 offer 表示公告额度，exec 表示实际执行，cap 表示市场或采购容量。数值契约使用原有带单位的字段名，符号统一保持接口与动作维数原样。

| UC、消费者终端责任：式（29） | 终端系数 × 剩余任务 kWh | 真正终止时直接计价一次 | 元等值 |
| $\widehat R,J_j,V_{\omega_j},\delta_{j,t},\widehat A_{j,t}$ | 奖励、折扣和价值递推 | 奖励已完成时间换算，直接递推 | 元等值 |
| $L_i^{clip},\widehat W,\widehat\epsilon_i^{NE},\widehat\epsilon_C^{NE},\widehat\epsilon_U^{SE}$ | 无量纲概率比或目标差 × 回报 | 直接评价或比较；优势归一化按训练配置另记 | 元等值（原始尺度） |

式（6）的 UC 到期项属于逐次考核，式（20）的消费者等待和逾期项属于持续时间成本。两者保留既定责任设计，分别记录考核次数与持有时长。金额汇总、终端结算和长期回报接收已经换算完成的结果。

# 第二部分　UC 的 Observation、Action、Reward

## 3. UC 的 Observation：资源与聚合信息

### 3.1 决策时刻与信息边界

UC 在本期消费者行动之前取得观测，然后一次提交六维调度动作。UC Actor 和 UC Value 使用同一套聚合输入；个人基线、队列、月账本、不适系数和策略参数留在消费者与结算模块。环境内部状态用于执行和核对，与 UC 网络输入分开。

### 3.2 聚合观测清单

$$
\begin{aligned}
o_t^U=[&t,T_{remain},E,p^{DER},\bar p^{PG},w,\chi,T^{DR},\\
&\sum_i p_i^{base},\sum_i p_i^{rigid},\sum_i\bar p_i^{flex},\sum_i p_i^{due},T^{U,avg},\\
&\sum_i q_i^{(0)},\ldots,\sum_i q_i^{(H)},\\
&p_{t-1}^{DER,sold},p_{t-1}^{UC,sold},p_{t-1}^{DR,net},\\
&\sum_i C_{i,t-1}^{DR},\sum_i p_{i,t-1}^{lost},C_{t-1}^{cash}].
\end{aligned}
$$

按 $t,T_{remain}$ 各占一维计算，观测含 13 个当前标量、$H+1$ 个聚合截止桶和 6 个上期标量，维度为 $H+20$。回合开始时上期反馈取零；连续模式的 $T_{remain}$ 取 −1。$t$ 使用能对应公共价表的时间索引；跨日、跨月或分时表变化的场景同步保留公开日历编码。

| 信息 | 单位 | 决策用途 |
|---|---|---|
| 时间与剩余期数 | 时段 | 分时价、调度时机、终端处理 |
| 电池电量 $E$ | kWh | 当前充放电空间 |
| DER 出力、PG 物理上限 | kW | 可分配资源 |
| PG 采购价、聚合零售价 | 元/kWh | 当前经营关系 |
| DR 事件与补偿价 | 无量纲、元/kWh | 采购是否开放及补偿成本 |
| 聚合基线、刚性、柔性和到期回补 | kW | 总需求、调节空间与当期责任 |
| 聚合截止桶 | kWh | 未来回补压力 |
| 上期成交、DR、补偿、失供与现金 | kW 或元 | 已实现的消费者响应反馈 |

总到期回补必须先按个人能力计算再汇总：$\sum_i p_i^{due}=\sum_i\min(D_i^{due}/\Delta t,\bar p_i^{flex})$。聚合接口只返回总量。聚合待办电量和聚合到期电量分别由截止桶求和和第零桶得到，不重复增加输入字段。

当前阶梯电价用聚合特征 $T^{U,avg}$ 表示：当 $\sum_i(p_i^{base}+p_i^{due})>0$ 时，取 $\sum_iT_i^U(p_i^{base}+p_i^{due})/\sum_i(p_i^{base}+p_i^{due})$；分母为零时取零。实际账单仍逐户使用 $T_i^U$。该均价压缩了价格与负荷分布；阶梯异质性对照可使用各阶梯匿名聚合负荷，并记录增加的维度。

### 3.3 固定配置、预测与历史

设备上下限、效率、步长、最大 DR 采购量和固定成本由 agent 配置绑定。同一场景内固定的参数不重复进入观测；跨场景变化时加入条件输入。UC 可保存自己的历史行动与聚合反馈；历史编码按同一信息边界使用。

本轮消费者的削减、移峰、报价、实际净 DR 和实际补偿在公告后产生，进入结算与下一期反馈。未来预测仅在数据源提供时加入，并注明预测期与实现期。

### 3.4 聚合观测的适用范围

UC 在聚合信息下进行部分可观测决策。汇总量减少个人明细披露，但丢失个体状态与参数的联合分布；单户或小群体聚合也存在反推风险。本文将输入隔离作为模型的信息边界，正式隐私保证需要聚合协议及相应证据。


## 4. UC 的 Action：六维调度与联合约束

### 4.1 六维动作及调度含义

UC 的行动写为：

$$
a^U=(p^{PG,offer},p^{curt},p^{ch,DER},p^{ch,PG},p^{dis,offer},p^{DR,cap}).
\tag{1}
$$

| 变量 | 单位 | 决策含义 | 作用路径 |
|---|---|---|---|
| $p^{PG,offer}$ | kW | PG 进口供给额度 | UC 容量、实际进口和售电 |
| $p^{curt}$ | kW | 主动退出的 DER 功率 | DER 容量、来源成交和弃电成本 |
| $p^{ch,DER}$ | kW | DER→ESS 充电功率 | DER 分流与未来 SOC |
| $p^{ch,PG}$ | kW | PG→ESS 充电功率 | PG 额度分流与未来 SOC |
| $p^{dis,offer}$ | kW | ESS 放电供给额度 | 当期 PG 替代与电池消耗 |
| $p^{DR,cap}$ | kW | DR 可补偿采购上限 | 消费者激励与 UC 支出 |

购电与放电采用**额度决策**：UC 决定愿意开放的资源上限，市场决定使用量。充电与主动弃电采用**功率决策**：合法值直接确定本期资源投入和退出。总充电功率 $p^{ch,DER}+p^{ch,PG}$、最终售电量和期末 SOC 由执行公式派生。

这种参数化给 UC 保留了资源选择权，并使每种动作有对应的能量去向与经济后果。额度闲置、储能积累和弃电均保存在结果中。

### 4.2 设备参数与联合可行域

设电池允许电量为 $[E_{min},E_{max}]$，充放电功率上限为 $\bar p^{ch},\bar p^{dis}$，效率为 $\eta_c,\eta_d$。可用放电能力为 $p^{dis,avail}=\min(\bar p^{dis},\eta_d(E-E_{min})/\Delta t)$。$\bar p^{DR}$ 为场景配置给定的最大 DR 采购功率，单位 kW，取非负有限值；主规格在同一场景内固定该上限，事件状态 $\chi$ 决定本期是否开放采购。UC 在以下联合域内行动：

$$
\begin{aligned}
&0\le p^{PG,offer}\le\bar p^{PG},\quad 0\le p^{ch,PG}\le p^{PG,offer},\\
&0\le p^{curt},p^{ch,DER},\quad p^{curt}+p^{ch,DER}\le p^{DER},\\
&p^{ch,DER}+p^{ch,PG}\le\min\left(\bar p^{ch},\frac{E_{max}-E}{\eta_c\Delta t}\right),\\
&0\le p^{dis,offer}\le p^{dis,avail},\quad (p^{ch,DER}+p^{ch,PG})p^{dis,offer}=0,\\
&0\le p^{DR,cap}\le\chi\bar p^{DR}.
\end{aligned}\tag{2}
$$

各组约束分别承担以下作用：

| 约束 | 物理意义 |
|---|---|
| $p^{PG,offer}\le\bar p^{PG}$、$p^{ch,PG}\le p^{PG,offer}$ | PG 售电与充电共同使用进口额度 |
| $p^{curt}+p^{ch,DER}\le p^{DER}$ | DER 在主动弃电、充电和市场供给之间分流 |
| 总充电功率与能量上限 | 充电满足设备额定功率及 SOC 空间 |
| 放电功率与可用电量上限 | 放电满足功率能力和存量边界 |
| 充放电互斥 | 两路充电合计与放电额度不能同时为正；均为零表示空闲 |
| 事件采购边界 | DR 支出额度由事件状态控制 |

可行域在 UC 行动前确定。神经网络一次输出控制参数，由策略输出层依据式（2）生成完整的六维可行动作；环境按同一组约束验证并执行提交值。零资源、满电池或事件关闭等状态下，受限坐标按其可行域执行确定值。

### 4.3 资源分流形成市场公告

UC 行动后，两类市场容量为：

$$
p^{DER,cap}=p^{DER}-p^{curt}-p^{ch,DER},\qquad
p^{UC,cap}=p^{PG,offer}+p^{dis,offer}-p^{ch,PG}.
\tag{3}
$$

DER 出力分成主动弃电 $p^{curt}$、充电 $p^{ch,DER}$ 和可售容量 $p^{DER,cap}$。PG 额度先满足充电 $p^{ch,PG}$，其余额度与 ESS 放电一起构成 $p^{UC,cap}$。

两池容量在消费者行动前冻结。消费者据此安排 DR 和订单；市场据此分配功率；物理模块据成交使用资源。公告之外的资源分别记录为保留电池、未开放的 PG 进口能力和主动弃电；电池存量跨期保留，进口能力与 DER 出力按下一时段数据重新加载。

### 4.4 策略输出与执行接口

网络一次输出内部控制参数，由策略输出层生成满足联合约束的六维物理行动。原行动域保留，具体参数化见第 13.2 节。环境校验合法性后保存并执行提交值；服务考核只进入奖励计算。

## 5. UC 的 Reward：经营收益与供给责任

### 5.1 UC 现金利润

$$
\begin{aligned}
C^{PG}&=wp^{PG,exec}\Delta t,\\
C^{DER,op}&=k_R(p^{DER}-p^{spill})\Delta t,\\
C^{cash}&=\sum_i C_i^{bill}-C^{PG}-C^{DER,op}-C^{ext}.
\end{aligned}\tag{4}
$$

| 现金项目 | 方向与计费依据 |
|---|---|
| 电费 $C_i^{energy}$ | 消费者向 UC 支付，按实际成交电量 |
| DR 补偿 $C_i^{DR}$ | UC 向正响应消费者支付，按采购份额 |
| 失供赔偿 $C_i^{comp}$ | UC 向受损消费者支付，按原生失供电量 |
| PG 采购 $C^{PG}$ | UC 向外部 PG 支付，按实际进口 |
| DER 运行 $C^{DER,op}$ | 使用 DER 电量的运行现金成本 |
| 其他支出 $C^{ext}$ | 具有明确收款方的外部现金，基础场景取零 |

消费者净转账合计减去外部现金成本，恰好形成 UC 现金利润。社区内部电费与返款在总体资金核对中相抵。

$w,k_R$ 均为元/kWh，PG 与 DER 的实际使用功率分别乘 $\Delta t$。$C^{ext}$ 接收已经计算完成的本期金额：上游若按小时收费，应先换算成本期金额；若为一次性支出，则归入发生该支付的时段。

### 5.2 储能退化、弃电成本与经营收益

$$
\begin{aligned}
C^{ESS}&=k_E(p^{ch,DER}+p^{ch,PG}+p^{dis,exec})\Delta t,\\
C^{spill}&=k_a p^{spill}\Delta t,\\
C^{book}&=C^{cash}-C^{ESS}-C^{spill}.
\end{aligned}\tag{5}
$$

储能退化按交流侧总吞吐电量计量，弃电机会成本按实际弃电电量计量。$C^{book}$ 作为经营分析指标保留；奖励直接展开现金和各项成本，不经该中间量转写。$k_E,k_a$ 均为元/kWh，对应功率各乘一次 $\Delta t$。电池效率用于式（25）的存量更新，这里的退化系数按已声明的交流侧吞吐口径标定。$C^{book}$ 在现金利润上扣除这两项经济成本，反映本期经营结果。

### 5.3 公告供给充足性考核

UC 的必要供给参照在行动前冻结为 $\sum_i(p_i^{base}+p_i^{due})$。两池公告容量由本期六维动作确定，消费者的主动减载不直接注销参照责任。正补偿价事件内，实际付费采购量 $\min(p^{DR,cap},p^{DR,net})$ 抵扣同量供给要求；公告采购上限本身不抵扣。

$$
\begin{aligned}
C^{UC,service}={}&\lambda_n\Bigl[
\sum_i(p_i^{base}+p_i^{due})-p^{DER,cap}-p^{UC,cap}\\
&\qquad-\mathbf{1}_{\{\chi=1,\ T^{DR}>0\}}
\min(p^{DR,cap},p^{DR,net})\Bigr]_+\Delta t
+\lambda_d\sum_iV_i^{due}.
\end{aligned}\tag{6}
$$

$\mathbf{1}_{\{\chi=1,T^{DR}>0\}}$ 在事件开放且补偿价为正时取 1，其余取 0。零补偿价采购额度不能获得供给抵扣。$\lambda_n$ 为公告供给缺口的单位考核系数，元/kWh；$\lambda_d$ 仍为每次期末对到期残留量考核的元/kWh。第一项对 kW 缺口乘一次 $\Delta t$，第二项直接对 kWh 残留量计价。

该项是 UC 效用账本的服务成本，实际现金赔偿继续按消费者调整后发生的原生失供量计算。环境在消费者响应后计算考核；UC 原行动、两池容量、固定充电和主动弃电均按原值执行。供给充足时的自主减载不产生额外缺口考核。真实资源不足和 UC 自主保留造成的缺口分别诊断。

供给考核给 UC 三种经济选择：开放容量、付费采购以抵扣容量要求，或承担考核以保留资源。原物理可行域保留，调度自主权通过这些选择及其跨期价值体现。系数的参数范围与新激励见第 25.3 节。


### 5.4 DR 服务估值与 UC 本期奖励

$$
C^{DR,value}=v^{DR}p^{DR,net}\Delta t,\quad v^{DR}\ge0.
\tag{7}
$$

$v^{DR}$ 的单位为元/kWh，表示 UC 对净请求减载的服务估值。基础经济场景取零；服务偏好场景使用明确的正值。该项归入效用账本，实际资金转移由电费、补偿和赔偿描述。

DR 服务估值取决于净请求减载，固定消费者响应时不因采购标签改变；供给不足时，实际付费 DR 还会降低第 5.3 节的供给考核。这两项经济作用分别记录。

$$
R_U=C^{cash}-C^{ESS}-C^{spill}+C^{DR,value}-C^{UC,service}.
\tag{8}
$$

UC 每个物理时段取得一次本期奖励。$C^{cash},C^{ESS},C^{spill},C^{DR,value},C^{UC,service}$ 已形成金额或元等值，汇总直接加减。有限期真正结束时追加 $v_E(E_T-E_0)-\lambda_U^{term}\sum_i B_{i,T}$；连续采样截断使用 bootstrap，终端处理见第 10.8 节。

# 第三部分　Consumer 的 Observation、Action、Reward

## 6. Consumer 的 Observation：个人状态与公开公告

### 6.1 决策所需的个人状态与公共条件

消费者观测由时间、本人负荷与费率、UC 资源公告及个人任务组成：

$$
\begin{aligned}
o_i=[&t,T_{remain},p_i^{base},p_i^{rigid},\bar p_i^{flex},M_i,\\
&T_i^U,T^R,\bar b_i^R,T^{DR},p^{DR,cap},\chi,\\
&p^{DER},\bar p^{PG},p^{dis,avail},p^{PG,offer},p^{curt},\\
&p^{ch,DER},p^{ch,PG},p^{dis,offer},p^{DER,cap},p^{UC,cap},\bar B_i,\\
&q_i^{(0)},q_i^{(1)},\ldots,q_i^{(H)}].
\end{aligned}
\tag{9}
$$

向量包括 23 个标量及 $H+1$ 个截止桶，维度为 $H+24$。有限期 $T_{remain}=T-t$，连续模式取 −1。

### 6.2 字段、单位和用途

| 位置 | 字段 | 单位 | 作用 |
|---|---|---|---|
| 1—2 | $t,T_{remain}$ | 时段 | 时间与收尾任务边界 |
| 3 | $p_i^{base}$ | kW | 基线和当前请求 |
| 4 | $p_i^{rigid}$ | kW | 刚性负荷保留 |
| 5 | $\bar p_i^{flex}$ | kW | 本地共享柔性预算 |
| 6 | $M_i$ | kWh | 月累计及零售阶梯状态 |
| 7—9 | $T_i^U,T^R,\bar b_i^R$ | 元/kWh | 电费和 DER 合法报价区间 |
| 10—12 | $T^{DR},p^{DR,cap},\chi$ | 价格、kW、标志 | 当期 DR 采购条件 |
| 13—15 | $p^{DER},\bar p^{PG},p^{dis,avail}$ | kW | 原始资源能力 |
| 16—20 | $p^{PG,offer},p^{curt},p^{ch,DER},p^{ch,PG},p^{dis,offer}$ | kW | UC 已选择的能源配置 |
| 21—22 | $p^{DER,cap},p^{UC,cap}$ | kW | 两池可成交容量 |
| 23 | $\bar B_i$ | kWh | 新任务容量边界 |
| 后续 $H+1$ 项 | $q_i^{(0)},\ldots,q_i^{(H)}$ | kWh | 本人截止与回补状态 |

桶 $q_i^{(0)}$ 合并当前到期与逾期量，$q_i^{(h)}$ 对应 $t+h$ 到期电量。因此 $B_i=\sum_hq_i^{(h)}$，$D_i^{due}=q_i^{(0)}$。模型使用统一的逾期持有系数，完整 FIFO 列表承担具体任务追踪。

### 6.3 信息可见性与参数条件

消费者读取本人任务、能力、费率以及公共资源公告。其他消费者的私有状态和本轮待生成动作构成部分可观测性。UC 公告容量在决策前确定，实际成交、实际进口和服务结果在出清后产生。

固定的延期、步长、成本和设备参数由 agent 配置绑定；跨场景变化的参数进入相应条件输入。观测字段顺序、归一化尺度和规则版本随数据契约存档。

## 7. Consumer 的 Action：削减、移峰与交易

### 7.1 战略变量及其作用

$$
a_i=(p_i^{cut},p_i^{shift},\rho_i,b_i^R).
\tag{10}
$$

| 变量 | 决策含义 | 作用路径 |
|---|---|---|
| $p_i^{cut}$ | 本期削减功率 | 当前需求、不适和净 DR |
| $p_i^{shift}$ | 移出或回补功率 | 任务、当前需求和跨期成本 |
| $\rho_i$ | 初始 DER 意向比例 | 资源申购和来源分配 |
| $b_i^R$ | DER 买方报价 | 稀缺排序和实际付款 |

Actor 生成请求和报价，市场生成成交，物理与任务模块生成实际完成量。该顺序将战略变量与其经济结果连接起来。

### 7.2 可调整负荷和历史任务

消费者本期基线为 $p_i^{base}$，其中 $p_i^{rigid}$ 是必须保留的刚性负荷；可调整部分直接写为 $p_i^{base}-p_i^{rigid}$。$\bar p_i^{flex}$ 是削减、移出和回补共享的功率上限。它约束本期调整幅度，由设备与场景给定。

历史任务保留两个电量字段：$B_i$ 为全部待办电量，$D_i^{due}$ 为其中本期到期及已逾期的电量，满足 $0\le D_i^{due}\le B_i\le\bar B_i$。先为到期任务预留能力内的最低回补请求：

$$
p_i^{due}=\min\left(\frac{D_i^{due}}{\Delta t},\bar p_i^{flex}\right).
\tag{11}
$$

$D_i^{due}/\Delta t$ 是在本期完成到期任务所需的功率，$\bar p_i^{flex}$ 是设备能够承担的上限。由于到期量属于待办量，$B_i/\Delta t$ 已由第一项覆盖，不再重复写入最小值。

例如，15 分钟为 $\Delta t=0.25$ h，到期任务 2 kWh 需要 $2/0.25=8$ kW 才能在本期完成。若调节上限为 4 kW，则最低请求为 4 kW，足量服务时完成 $4\times0.25=1$ kWh，剩余 1 kWh 继续保留。这里的功率描述完成任务的速度，电量描述任务总量。

### 7.3 用两个动作表示三种负荷调整

负荷调整只使用削减功率 $p_i^{cut}\ge0$ 和带符号移峰功率 $p_i^{shift}$。削减永久取消当前用电；移峰正值把当前任务移向未来，负值请求执行历史任务，零值表示本期不移峰。

$$
\text{移出功率}=[p_i^{shift}]_+,\qquad
\text{回补请求功率}=[-p_i^{shift}]_+.
\tag{12}
$$

| 动作或表达式 | 物理含义 | 任务处理 |
|---|---|---|
| $p_i^{cut}$ | 永久削减的本期用电功率 | 计调整不适，不创建待办任务 |
| $p_i^{shift}>0$ | 从本期移向未来 | 创建 $p_i^{shift}\Delta t$ kWh 任务 |
| $p_i^{shift}<0$ | 请求回补历史任务 | 请求功率为 $-p_i^{shift}$，成交后再计算实际完成量 |
| $p_i^{shift}=0$ | 本期不移峰 | 队列只按既有状态滚存 |

一个带符号动作自然保持移出与回补互斥，削减可以与所选方向共同使用调节能力。实际回补由第 10.5 节的服务结果确定。

### 7.4 条件可行域：先削减，再移峰

首先为到期回补预留功率，再采样削减：

$$
0\le p_i^{cut}\le\min\left(
p_i^{base}-p_i^{rigid},\bar p_i^{flex}-p_i^{due}\right).
\tag{13}
$$

选择削减后，直接把移出与回补上限写入带符号动作的边界：

$$
\begin{aligned}
-\min\left(\bar p_i^{flex}-p_i^{cut},\frac{B_i}{\Delta t}\right)
&\le p_i^{shift},\\
p_i^{shift}&\le
\begin{cases}
\min\left(p_i^{base}-p_i^{rigid}-p_i^{cut},
\bar p_i^{flex}-p_i^{cut},\frac{\bar B_i-B_i}{\Delta t}\right),
&p_i^{due}=0,\\
-p_i^{due},&p_i^{due}>0.
\end{cases}
\end{aligned}\tag{14}
$$

负方向同时受剩余调节能力和待办电量限制。正方向同时受剩余可调整原生负荷、剩余调节能力和队列空间限制，这三个上限各自承担独立约束。

有限期中，当 $t+H>T-1$ 时关闭新移出：仅在 $p_i^{due}=0$ 的分支将式（14）的正方向上限取零，此时允许等待或回补；若 $p_i^{due}>0$，仍保留上限 $-p_i^{due}$，必须提出能力内的到期回补请求。连续运行保留开放的任务时域。来源比例与报价仍在原区间中采样：

$$
\rho_i\in[0,1],\qquad b_i^R\in[T^R,\bar b_i^R].
\tag{15}
$$

当 $p_i^{due}>0$ 时，$p_i^{shift}\le-p_i^{due}$ 强制提出能力内的到期回补请求。式（13）保证剩余调节能力不少于 $p_i^{due}$，而 $D_i^{due}\le B_i$ 保证任务余额足够，因此负方向区间始终非空。

### 7.5 本期需求与服务优先级

保留三种具有不同业务含义的需求功率：本期原生需求、总用电请求和必要层请求。

$$
\begin{aligned}
p_i^{native}&=p_i^{base}-p_i^{cut}-[p_i^{shift}]_+,\\
p_i^{req}&=p_i^{base}-p_i^{cut}-p_i^{shift},\\
p_i^{nec}&=p_i^{native}+p_i^{due}.
\end{aligned}\tag{16}
$$

| 功率 | 含义 |
|---|---|
| $p_i^{native}$ | 削减和移出之后，仍应在本期服务的原生需求 |
| $p_i^{req}$ | 原生需求加历史回补请求；移峰负值直接增加该请求 |
| $p_i^{nec}$ | 原生需求加能力内到期回补，作为第一层出清请求 |
| $p_i^{req}-p_i^{nec}$ | 超过最低到期请求的提前回补，作为第二层请求 |

DER 初始意向直接写为 $\rho_i p_i^{req}$。提前回补量和来源意向按这些表达式计算，分别进入市场，不再为它们另设简称。由于历史任务叠加，总请求可以超过原始基线。

### 7.6 价格和报价区间

UC 零售价取外生公告规则 $T_i^U=T^U(t,M_i)$。当期单价在行动前冻结，月累计通过实际 UC 购电更新。$\bar T^U$ 定义为该场景价表中所有适用消费者、时段和阶梯的最高 UC 零售价，单位元/kWh；每个适用 $T_i^U$ 均不超过它。DER 报价区间由 $T^R$ 和 $\bar b_i^R=\min(\bar b^R,T_i^U)$ 确定，下限不高于上限。

DER 成交按 $b_i^R$ 支付，UC 成交按 $T_i^U$ 支付。两种价格直接进入消费者账单和 UC 收入。

### 7.7 初始来源比例和条件订单

DER 初始意向为 $\rho_i p_i^{req}$，其余需求进入 UC 分配。每户提交一个包含两层请求、来源意向和报价的订单。DER 意向用于首轮分配；UC 供给不足且 DER 仍有余量时，同一订单继续按原报价补配。

这种来源偏好保留消费者的资源选择，同时使市场能在必要层内充分利用已公告供给。

## 8. Consumer 的 Reward：电费、DR 与服务成本

### 8.1 个人减载与全体净减载

DR 计量比较原始基线与消费者本期总请求。每户减载和全体净减载写为：

$$
\begin{aligned}
p_i^{DR}&=\chi\left(p_i^{base}-p_i^{req}\right),\\
p^{DR,net}&=\left[\sum_i p_i^{DR}\right]_+.
\end{aligned}\tag{17}
$$

个人减载为正，表示请求减少；为负，表示历史回补使请求增加。由式（16），基线与请求之差等于 $p_i^{cut}+p_i^{shift}$，因此这一写法保留削减、移出和回补的原有计量。

全体净减载先合计正负响应，再取正值。例如，一户削减 4 kW，另一户请求回补 4 kW，全体净减载为零。计量使用消费者请求，市场服务缺口另记失供；FIFO 始终按实际完成量更新。

事件内 $\chi=1$，事件外 $\chi=0$。消费者物理调整仍受第 7 节的本地可行域约束。

### 8.2 直接计算个人补偿

**先确定 UC 的本期 DR 总补偿金额，再按各户正减载份额分摊。** 当正减载合计大于零时，直接计算：

$$
C_i^{DR}=
\underbrace{T^{DR}\Delta t\min\left(p^{DR,cap},p^{DR,net}\right)}_{\text{全体补偿金额}}
\cdot
\underbrace{\frac{[p_i^{DR}]_+}{\sum_j[p_j^{DR}]_+}}_{\text{本户正减载份额}}.
\tag{18}
$$

当 $\sum_j[p_j^{DR}]_+=0$ 时，所有 $C_i^{DR}=0$。公式的两个部分分别承担以下作用：

- **全体补偿金额**：采购上限与全体净减载取较小值，乘以时长和补偿单价。
- **本户份额**：本户正减载占全部正减载的比例；净增载户的份额为零。

因此，全体补偿按净减载和采购上限共同控制，个体补偿按正贡献分摊。正响应合计和付费功率直接代入金额公式，不再为这些中间结果另设符号。

$T^{DR}$ 按元/kWh 计价，最小值的单位为 kW，因此总补偿只乘一次 $\Delta t$；本户正贡献份额无量纲，分摊时直接乘总金额。

沿用第 11.1 节的三户行动，个人减载分别为 2、1、−1 kW，全体净减载为 2 kW，正减载合计为 3 kW。采购上限为 2 kW、补偿价为 0.20 元/kWh、时长为 0.25 h 时，总补偿为 0.10 元；A、B、C 的份额为 $2/3,1/3,0$，得到 0.066667、0.033333、0 元。

事件外补偿价和采购上限均为零。日志可以继续记录正响应合计、采购功率与个体份额，结算直接使用 $C_i^{DR}$。

### 8.3 双边电费与失供赔偿

$$
C_i^{energy}=(b_i^R p_i^{DER}+T_i^U p_i^{UC})\Delta t,\quad
C_i^{comp}=\alpha_i p_i^{lost}\Delta t,\quad C_i^{bill}=C_i^{energy}-C_i^{DR}-C_i^{comp}.
\tag{19}
$$

$C_i^{energy}$ 为消费者能源电费，$C_i^{DR}$ 为 UC 支付的 DR 补偿，$C_i^{comp}$ 为本期原生失供赔偿。净账单 $C_i^{bill}$ 表示本户向 UC 的净资金转移。

两项电费和失供赔偿均以本期电量计价，功率各乘一次 $\Delta t$。$C_i^{energy},C_i^{DR},C_i^{comp}$ 已经是元，净账单直接加减这些金额。

赔偿基数为 DR 后剩余原生需求的实际失供量。主合成配置取 $\alpha_i=1.00$ 元/kWh，作为公告中的结算参数；到期任务责任进入 UC 服务考核。两类责任分别对应本期原生服务和历史履约。

### 8.4 消费者成本与奖励

$$
\begin{aligned}
C_i^{flex}&=\kappa_i\frac{(p_i^{cut})^2+([p_i^{shift}]_+)^2}
{\max(p_i^{base},\epsilon)}\Delta t,\\
C_i^{service}&=\lambda_i^n p_i^{lost}\Delta t+\lambda_i^B B_i'\Delta t
+\lambda_i^{late}V_i^{due}\Delta t,\\
R_i&=-\left(C_i^{bill}+C_i^{flex}+C_i^{service}\right).
\end{aligned}
\tag{20}
$$

柔性不适使用二次调整量，并按基线和步长单位化。分子的单位为 kW²，分母为 kW，商仍为 kW；与 $\kappa_i$ 及 $\Delta t$ 相乘后得到本期元等值。服务代价包含原生失供、期末任务等待和到期迟延。回补本身承担购电费和功率占用，其任务完成通过减少等待与迟延成本体现。

$\kappa_i,\lambda_i^n$ 的单位为元/kWh，$\lambda_i^B,\lambda_i^{late}$ 为元/(kWh·h)。$B_i',V_i^{due}$ 已经是 kWh，这两项乘 $\Delta t$ 是计入等待或逾期的持续时长；本模型沿用期末余额乘本期时长的离散计量。$\epsilon>0$ 的单位为 kW，使零基线状态的分母保持正值。主合成配置取 $\lambda_i^n=2.00$ 元/kWh，并在参数分析中比较失供代价、赔偿和零售单价。

$C_i^{bill},C_i^{flex},C_i^{service}$ 已经是本期金额或元等值，消费者奖励直接取总成本的负值。

UC 和消费者分别拥有服务效用，社会评价另按明确的汇总口径组织；双边支付与主观成本分别统计。

### 8.5 有限期与连续目标

有限期真正结束时，消费者追加 $-\lambda_i^{term}B_{i,T}$，每户剩余任务按元/kWh 一次结算；连续运行保留任务状态并按下一价值 bootstrap。普通成本与终端成本对应的电量不再重复乘 $\Delta t$。

# 第四部分　市场出清与环境执行

## 9. 市场：DER PAB、UC 比例分配与结算

### 9.1 同层分配规则

DER 按买方报价从高到低处理。设同价组总申购为 $p_b^{req}$，到该组时剩余 DER 为 $p^{rem}$，则每户得到自己的申购量乘以 $\min(1,p^{rem}/p_b^{req})$；零请求组分配为零。

UC 使用相同的比例思想处理剩余需求。当前层请求总量为 $p^{UC,req}$、剩余 UC 容量为 $p^{rem}$ 时，每户得到剩余请求乘以 $\min(1,p^{rem}/p^{UC,req})$；总请求为零时，该层分配为零。

高报价承担高的实际支付，同价或同优先级通过比例分配保持顺序无关性。

### 9.2 第一层：原生需求与到期回补

对所有消费者的必要需求 $p_i^{nec}$，依次执行：

1. 以 $\min(\rho_i p_i^{req},p_i^{nec})$ 作为 DER 首轮申购，按 PAB 成交。
2. 将本户剩余必要请求投入 UC，按比例分配。
3. 对尚未满足的必要请求，使用剩余 DER 按原报价补配。

每步扣减已经使用的池容量。整个必要层结束后，形成各户必要层 DER 成交 $p_i^{DER,nec}$、UC 成交和缺口。

### 9.3 第二层：可提前回补

本层请求为 $p_i^{req}-p_i^{nec}$，DER 首轮意向为 $\min(p_i^{req}-p_i^{nec},[\rho_i p_i^{req}-p_i^{DER,nec}]_+)$。随后依次执行 DER 首轮、UC 剩余分配和 DER 补配。

第二层使用第一层之后的剩余容量。必要层尚有缺口时，两池剩余容量已经耗尽，提前回补成交为零。

### 9.4 分配上限与总服务量

$$
0\le p_i^{serve}\le p_i^{req},\quad\sum_i p_i^{DER}\le p^{DER,cap},\quad\sum_i p_i^{UC}\le p^{UC,cap}.
\tag{21}
$$

两层处理使每户服务上限和两池容量同时成立。由于每层完成跨来源补配，市场总服务满足：

$$
\sum_i p_i^{serve}=\min\left(\sum_i p_i^{req},p^{DER,cap}+p^{UC,cap}\right).
\tag{22}
$$

式（22）描述**公告供给的充分利用**。资源充裕时请求全部满足；请求超过公告总量时形成缺口。UC 保留资源、主动退出量和充电投入通过公告容量进入服务结果。

### 9.5 结算的计算顺序

全部消费者行动齐备后，市场按原公告容量分配；环境据成交执行资源与 FIFO，再按第 8 节计算净请求 DR、电费、补偿和失供赔偿。第 5 节汇总 UC 现金、经营收益、公告供给考核及奖励。公告供给考核使用入期基线和能力内到期回补，付费抵扣使用本轮已实现的 DR 付款。各模块保存输入快照与同一物理时段 ID。

## 10. 环境：资源执行、任务与状态转移

### 10.1 市场成交落实为 PG 与 ESS 执行

令 DER、UC 总成交分别为 $p^{DER,sold}=\sum_i p_i^{DER}$、$p^{UC,sold}=\sum_i p_i^{UC}$。UC 电源按公告内 ESS 优先、PG 填补的固定顺序执行：

$$
\begin{aligned}
p^{dis,exec}&=\min\left(p^{dis,offer},p^{UC,sold}\right),\\
p^{PG,exec}&=p^{UC,sold}+p^{ch,PG}-p^{dis,exec}.
\end{aligned}
\tag{23}
$$

两路充电直接执行 $p^{ch,DER}$ 和 $p^{ch,PG}$，分别保留动作字段与实际执行字段，不另设相同数值的公式别名。这个顺序将 UC 已选择的放电额度用于成交需求，并由 PG 填补剩余售电和充电。充电模式下 $p^{dis,offer}=0$，PG 承担 $p^{UC,sold}+p^{ch,PG}$；放电模式下 $p^{ch,PG}=0$，放电承担最多 $p^{dis,offer}$ 的 UC 成交。

例如，UC 公告 PG 额度 4 kW、放电额度 2 kW，在 UC 成交 4 kW 时执行放电 2、进口 2。剩余 PG 额度保持闲置。若 UC 公告 PG 额度 4 并选择 PG 充电 2，则可售 UC 容量为 2；市场成交 2 时，实际进口 4，其中一半售电、一半充电。

原公告、实际使用和闲置额度是三个独立字段。由 $p^{UC,sold}\le p^{UC,cap}$ 及充放电互斥，可以推出 $p^{PG,exec}\le p^{PG,offer}$、$p^{dis,exec}\le p^{dis,offer}$。这条额度边界贯穿执行过程。

### 10.2 主动弃电与未售余量

$$
p^{unsold}=p^{DER,cap}-p^{DER,sold},\qquad
p^{spill}=p^{curt}+p^{unsold}=p^{DER}-p^{ch,DER}-p^{DER,sold}.
\tag{24}
$$

主动弃电反映 UC 的资源退出决策，未售余量反映 DER 公告容量的市场利用结果。两者共同构成实际弃电功率，分别进入诊断指标；合计功率乘以步长得到弃电电量，再进入弃电成本。

这样可以识别两种不同情景：UC 主动降低 DER 供给，以及 DER 已公告但没有被市场使用。来源选择的经济效应在第 25 节通过实际支付结构分析。

### 10.3 ESS 电量更新

$$
E'=E+\eta_c(p^{ch,DER}+p^{ch,PG})\Delta t-\frac{p^{dis,exec}\Delta t}{\eta_d},
\quad E_{min}\le E'\le E_{max}.
\tag{25}
$$

充入电池的输入能量乘以 $\eta_c$，向用户放出的能量除以 $\eta_d$ 后从电池扣除。确定充电 $p^{ch,DER}+p^{ch,PG}$ 积累下一期可用能量，实际放电消耗当前存量。这一状态转移形成 UC 跨期套利和资源保留的基础。

主规格采用无自放电的电池模型，其他设备损耗作为参数化扩展处理。

### 10.4 总功率平衡及推导

$$
p^{PG,exec}+p^{DER}+p^{dis,exec}=\sum_i p_i^{serve}+p^{ch,DER}+p^{ch,PG}+p^{spill},
\quad p_i^{serve}=p_i^{DER}+p_i^{UC}.
\tag{26}
$$

由式（23），$p^{PG,exec}+p^{dis,exec}=p^{UC,sold}+p^{ch,PG}$。由式（24），$p^{DER}=p^{ch,DER}+p^{DER,sold}+p^{spill}$。将两式相加，得到 PG、DER 和 ESS 的总供给恰好等于用户服务、充电和弃电。

功率平衡在成交充分、部分成交和零成交三种状态下使用同一组公式。PG 充电是确定的能量输入，闲置放电额度保留在电池中，DER 剩余以未售弃电计量。

### 10.5 服务分解与 FIFO 更新

每户实际获得的服务为 $p_i^{serve}=p_i^{DER}+p_i^{UC}$。先服务本期原生需求，再用剩余服务完成历史任务：

$$
\begin{aligned}
p_i^{lost}&=[p_i^{native}-p_i^{serve}]_+,\\
p_i^{repay}&=[p_i^{serve}-p_i^{native}]_+,\\
B_i'&=B_i+\left([p_i^{shift}]_+-p_i^{repay}\right)\Delta t.
\end{aligned}\tag{27}
$$

$p_i^{lost}$ 是本期原生失供功率，$p_i^{repay}$ 是实际完成的回补功率。市场保证 $p_i^{serve}\le p_i^{req}$，因此剩余服务已经不超过回补请求，无需再套一个请求上限的最小值。

回补按最早截止时间执行，同截止时间按创建顺序 FIFO。实际完成 $p_i^{repay}\Delta t$ kWh 后，再追加本期移出的任务，截止期为 $t+H$。请求用于购电和 DR 计量，实际完成量用于减少队列，未完成的请求继续保留为待办。

### 10.6 期限责任和队列容量

期末仍未完成的到期任务保留为：

$$
V_i^{due}=[D_i^{due}-p_i^{repay}\Delta t]_+,\qquad
0\le B_i'\le\bar B_i.
\tag{28}
$$

到期责任同时包含本地能力缺口和市场服务不足。其本地能力部分直接记录为 $[D_i^{due}-\bar p_i^{flex}\Delta t]_+$，该值不超过 $V_i^{due}$；日志保留原因分解，奖励仍按完整的到期责任计算。

移出受队列剩余空间限制，回补按实际完成量扣减，因此队列保持容量边界。软期限通过任务滚存和迟延成本表达，到期任务持续影响消费者和 UC 的后续决策。

### 10.7 电池、任务和月账本

电池由式（25）更新，任务由式（27）更新。月累计先以入期 $M_i$ 冻结 UC 单价，结算后增加 $p_i^{UC}\Delta t$；下一时段跨月时，重置下一期月累计。DER 电量单列。

TUTT 的分时表和累计阈值由配置提供，本模型采用每时段冻结单价。消费者通过实际购电改变未来阶梯状态，因此本期费用与后期费率形成另一条跨期联系。

### 10.8 有限期终端与连续运行

$$
R_{U,term}=v_E(E_T-E_0)-\lambda_U^{term}\sum_i B_{i,T},\qquad
R_{i,term}=-\lambda_i^{term}B_{i,T}.
\tag{29}
$$

有限期结束时，电池存量变化按 $v_E$ 计价，剩余任务按终端责任系数计价。$v_E,\lambda_U^{term},\lambda_i^{term}$ 均为元/kWh，$E_T-E_0,B_{i,T}$ 已经是 kWh，终端直接形成元等值。式（29）在最后一个物理时段真正终止时追加一次；一般时段使用常规奖励。初末差值使各策略使用相同的初始资源基准。输出同时列示初末 SOC、剩余任务、现金利润及存量调整后的目标。

连续跨日运行保留 SOC、队列和月累计。采样截断保留状态并按下一价值 bootstrap，有限期真正结束才应用终端项。严格循环 SOC 场景可作为独立约束对照。

### 10.9 原子状态提交

每期先生成完整候选结果：市场、物理、FIFO、DR、资金、成本、奖励、终端和下一状态。候选通过一致性检查后提交一次。失败保存当前阶段状态、输入和原异常，便于修正与复现。

UC 公告阶段保存原行动与资源条件；消费者阶段完成物理转移。transition ID 约束支付和更新的唯一性，快照同时保存阶段与公告。

## 12. Stackelberg–Nash 博弈定义

### 12.1 各参与者的长期目标

UC 策略记为 $\pi_U$，消费者策略为 $\pi_i$。以包含终端追加项的时段奖励 $\widehat R$ 定义：

$$
J_j(\pi_U,\pi_{1:N})=\mathbb E\left[\sum_{t=0}^{T-1}\gamma^t\widehat R_{j,t}\right].
$$

消费者最大化负成本，UC 最大化经营与服务目标。期望覆盖外生轨迹和策略随机性，折扣 $\gamma$ 以物理时段计量。$R,\widehat R$ 已经是单期元等值，$\gamma$ 无量纲，$J_j$ 直接累加折扣回报，单位仍为元等值。现金总额另外按未折扣的实际金额汇总。

有限期采用上述目标，允许 $0\le\gamma\le1$，$\widehat R$ 在真正终止时包含一次终端追加项。连续运行采用无限期折扣目标：

$$
J_j^{cont}(\pi_U,\pi_{1:N})=
\mathbb E\left[\sum_{t=0}^{\infty}\gamma^t R_{j,t}\right],\qquad 0\le\gamma<1.
$$

连续场景使用有界的负荷、价格、设备和成本参数，使单期奖励有界，折扣和因而有限。连续运行沿用式（8）—（28）的常规奖励；采样截断保留下一价值估计，按式（29）结算的真正终端仅属于有限期。观测中的 $T_{remain}=-1$ 是连续运行标志，与目标的求和上限分别定义。连续场景的 Nash 响应和 UC 上层评价使用 $J_j^{cont}$；后文以 $J_j$ 统称对应运行方式的目标。

### 12.2 固定 UC 后的消费者 Nash 响应

给定 $\pi_U$，消费者策略组满足：

$$
J_i(\pi_U,\pi_i^*,\pi_{-i}^*)\ge J_i(\pi_U,\pi_i,\pi_{-i}^*)
\quad\text{对所有允许的 }\pi_i,
$$

这一条件表示每户在固定 UC 与其他消费者时，当前策略达到自身目标的最佳响应。市场把共同资源约束作用于成交结果，个人行动域由本户状态和 UC 公告确定。

消费者竞争通过分配和支付进入 $J_i$，其响应关系包括报价、负荷调整及任务安排。单期出清负责计算给定行动的结果，策略层负责寻找跨期最佳响应。

### 12.3 UC 的上层响应优化

设消费者 Nash 响应集合为 $\mathcal N(\pi_U)$，按响应选择规则取 $\pi_C^*(\pi_U)$，领导者问题为：

$$
\max_{\pi_U}J_U\bigl(\pi_U,\pi_C^*(\pi_U)\bigr).
$$

UC 评价把自身资源决策与消费者对它的响应联系起来。多重响应场景可采用实际训练分支、乐观或悲观选择，并在实验协议中固定选择方法。

执行阶段的 UC 策略在整条评价轨迹上固定，每期依该策略生成公告。策略更新发生在训练层，候选接受依据重新响应后的收益。存在性、稳定性与搜索精度在第 22 节和研究状态表中分别组织。

## 13. Actor、可行输出层与 Critic

### 13.1 网络结构与执行路径

每个消费者维护独立的特征网络和策略参数，执行路径为：

$$
h_{i,t}=f_{\phi_i}(o_{i,t}),\qquad
a_{i,t}\sim\pi_{\theta_i}(\cdot\mid h_{i,t}).
$$

隐藏维度记为 $d_h$，观测维度为 $H+24$，物理动作维度为 4。隐藏特征承担状态表达，动作承担战略选择，成交承担物理分配。所有消费者行动齐备后，市场统一生成本期成交。

UC 使用独立网络读取供给侧观测，一次前向计算输出本期控制参数，策略输出层将其转换为式（1）的六维可行动作。消费者策略以本轮公告为条件，因此 UC 同一策略在不同资源状态下的公告，会直接进入消费者的行动分布。

### 13.2 UC 一次输出与联合可行行动

UC 的行动生成路径为：**供给侧观测 → 神经网络一次输出控制参数 → 策略输出层生成六维可行动作 → 环境校验并发布公告**。确定性策略输出内部控制值；随机策略一次输出分布参数，并据此取得本期内部控制值。六维始终指提交给市场的物理决策，网络输出参数量由策略分布设计决定。

策略输出层使用决策前的资源、电池和事件状态，统一满足式（2）的 DER 分流、PG 分流、总充电空间、放电能力、充放电互斥及 DR 采购边界。以下给出覆盖原联合可行域的一种固定映射，保留六个物理变量的选择范围。充电、放电和空闲由最终充放电功率体现；模型不再强制设置三个离散模式，也不规定各坐标的采样顺序。零宽可行坐标执行确定值。

网络一次生成六个内部控制值 $\mathbf{z}=(z_1,\ldots,z_6)$；随机策略一次生成其均值与标准差，再联合采样。固定区间变换给出无量纲控制值：

$$
u_k=\operatorname{clip}(z_k,0,1),\quad k\in\{1,2,3,4,6\},\qquad
u_5=\operatorname{clip}(z_5,-1,1).
$$

$u_5$ 为带符号的储能方向与幅度：正值允许充电，负值允许放电，零值为空闲。$u_3,u_4$ 分别控制两类来源的内部充电意向。内部意向功率 $p^{ch,int,DER},p^{ch,int,PG}$ 仅用于输出层计算，最终提交值仍为式（1）的六个变量：

$$
\begin{aligned}
p^{PG,offer}&=u_1\bar p^{PG},\qquad p^{curt}=u_2p^{DER},\\
p^{ch,int,DER}&=u_3[u_5]_+(p^{DER}-p^{curt}),\\
p^{ch,int,PG}&=u_4[u_5]_+p^{PG,offer},\\
p^{dis,offer}&=[-u_5]_+p^{dis,avail},\qquad p^{DR,cap}=u_6\chi\bar p^{DR}.
\end{aligned}
$$

两路内部意向共用充电功率与 SOC 空间，按同一无量纲比例 $\beta$ 转为最终充电功率：

$$
\begin{aligned}
\beta&=
\begin{cases}
\displaystyle\min\left(1,
\frac{\min\left(\bar p^{ch},(E_{max}-E)/(\eta_c\Delta t)\right)}
{p^{ch,int,DER}+p^{ch,int,PG}}\right),
&p^{ch,int,DER}+p^{ch,int,PG}>0,\\
0,&p^{ch,int,DER}+p^{ch,int,PG}=0,
\end{cases}\\
p^{ch,DER}&=\beta p^{ch,int,DER},\qquad p^{ch,PG}=\beta p^{ch,int,PG}.
\end{aligned}
$$

所有内部控制值同时生成，以上计算依赖属于固定输出层转换。$0\le\beta\le1$ 保持来源边界，公共比例满足总充电空间；$[u_5]_+[-u_5]_+=0$ 保持充放电互斥。无充电意向时直接使用零分支，无需除以零。对总充电功率为正的任一合法动作，可取 $u_5=1$，按目标功率与对应来源可用量确定 $u_3,u_4$，此时 $\beta=1$；合法放电动作由负 $u_5$ 表示。零来源取相应内部比例为零，空闲取 $u_5=0$。因此零供给、满额度、全弃电、充电、放电和空闲等原有边界均有对应内部控制值。

可行动作生成属于 UC 策略输出层，生成后的六维值就是本期 UC 决策。环境验证提交值，再按公告容量出清；非法输入按第 17.2 节处理。两路充电、主动弃电和供给额度继续保持第 4 节的执行语义。

本版随机策略在原始内部变量 $\mathbf{z}$ 空间定义概率。网络一次输出 $\mu^U,\sigma^U$，各 $\sigma_k^U>0$，使用六维对角高斯联合分布：

$$
q_{\theta_U}(\mathbf{z}\mid o^U)=
\prod_{k=1}^{6}\mathcal N(z_k;\mu_k^U, (\sigma_k^U)^2),\qquad
\log q_{\theta_U}(\mathbf{z}\mid o^U)=\sum_{k=1}^{6}\log\mathcal N(z_k;\mu_k^U, (\sigma_k^U)^2).
$$

$o^U$ 为第 3.2 节的 UC 决策前观测，$\mu^U,\sigma^U$ 均为六维无量纲网络输出；确定性策略取 $\mathbf{z}=\mu^U$。$\pi_U$ 是内部分布经固定输出层所诱导的物理行动策略。轨迹保存原始 $\mathbf{z}$、对应六维动作、决策前资源与聚合观测及行为 `log_prob`。采集与更新使用同一参数化和同一映射，UC 的 PPO 概率比为 $q_{\theta_U}(\mathbf{z}\mid o^U)/q_{old}(\mathbf{z}\mid o^U)$。上述可行映射只依赖固定规则、决策前状态和内部控制值，其规则在同一训练配置内保持不变。

概率计算使用裁剪前的 $\mathbf{z}$，保留被零宽坐标或互斥约束忽略的内部分量。这样多组内部控制值对应同一物理动作时，内部概率与物理动作密度分别处理；本版统一采用内部变量概率，不对六维物理动作套用普通高斯密度。此处定义行动生成与概率口径，生产网络和 Learner 的实现状态见第 23.3 节。

### 13.3 消费者条件分布

削减与移峰具有条件依赖，联合分布可按如下结构组织：

$$
\pi_i(a_i\mid o_i)=\pi_i(p_i^{cut}\mid o_i)
\pi_i(p_i^{shift}\mid p_i^{cut},o_i)
\pi_i(\rho_i,b_i^R\mid p_i^{cut},p_i^{shift},o_i).
$$

Actor 先得到削减值，再直接使用式（14）的条件边界生成移峰。所有边界使用决策前本人状态。归一化到物理区间的变换、Jacobian 和确定性维度与采样记录一起保存。

原论文 Fig. 4 的共享 Encoder 与个体 Decoder 提供网络结构对照。本文主线采用独立消费者 Actor，以各户观测生成各户行动。共享局部编码参数的对照方案保持相同观测、交易和奖励，通过统一数据与评估协议比较参数效率和响应质量。

### 13.5 两阶段状态价值

集中状态价值按决策时刻分别定义：

$$
V_{\omega_U}(o_t^U),\qquad V_{\omega_i}(s_t^C).
$$

UC Value 在上层行动前估计回报，消费者 Value 在 UC 公告后、下层行动前估计回报。UC Value 只读取第 3 节的聚合观测 $o_t^U$，不读取消费者个人明细。消费者集中 Value 的 $s_t^C$ 由受信训练服务提供，用于训练侧共同状态估计；环境全局状态保留在执行与消费者训练接口，不能作为 UC 网络的旁路输入。

本期行动、成交和服务结果用于奖励、训练标签及诊断。下一消费者 Value 使用下一轮公告形成的 $s_{t+1}^C$，通过轨迹索引回填相应经验。

状态价值 $V_{\omega_j}$ 预测折扣回报，采用元等值尺度；它与表示到期残留电量的 $V_i^{due}$ 分属价值函数和物理状态。

### 13.6 个体目标与历史表达

各消费者使用自身 $R_i$，UC 使用 $R_U$。UC 的 Actor 与 Value 使用聚合信息，消费者集中 Value 在受信训练端使用共同状态；分散执行以个人与公共观测行动，各参与者保留自身目标。

历史编码可用于处理其他消费者和未来外生状态的未知信息。实验分别记录网络记忆、参数共享与信息可见性设置；当前个人任务和资源公告始终通过固定 schema 提供。

## 14. 双层经验采样、更新与训练伪代码

### 14.1 一个物理时段的轨迹

| 经验对象 | 保存内容 |
|---|---|
| UC 经验 | $o_t^U$ 聚合观测、内部控制值与六维行动、输出层映射记录、行为概率、UC 奖励、下一 UC 状态 |
| 消费者经验 | $s_t^C$ 对应本人观测、四维行动、条件边界、行为概率、个人奖励、下一决策状态 |
| 环境记录 | 公告、成交、资源使用、队列、支付、终止与 transition ID |

U→C 阶段使用折扣 1，C→下一 U 使用物理折扣 $\gamma$。UC 与消费者各自的连续决策轨迹每期计一次物理折扣。真正终止和采样截断分别标记，截止处的下一 Value 由合法状态构造。

### 14.2 内层：固定 UC，学习消费者响应

固定外层第 $k$ 轮的 UC Actor 参数 $\theta_U^k$，全体参与者采集同一批新轨迹，先更新全部 Critic，再更新消费者 Actor。每个 Critic 使用对应参与者自己的奖励；UC Actor 在此阶段冻结。

对任一参与者，物理期 TD 与优势递推可写为：

$$
\delta_{j,t}=\widehat R_{j,t}+\gamma(1-d_t^{term})V_{\omega_j}(x_{t+1}^j)
-V_{\omega_j}(x_t^j),\qquad
\widehat A_{j,t}=\delta_{j,t}+\gamma\lambda_{GAE}m_t\widehat A_{j,t+1}.
$$

$\widehat R_{j,t}$ 包含真正终止时追加的式（29）项，与第 12.1 节目标一致。$d_t^{term}$ 标记真正终止，$m_t$ 在真正终止或样本段末尾取零，其余连续位置取一。截断保留合法下一状态的价值估计，并结束本段递推。本式 $x_t^j$ 为价值网络输入：UC 取 $x_t^U=o_t^U$，消费者取 $x_t^i=s_t^C$。UC 全局状态快照只用于环境诊断，不向 UC 网络开放。

例如采用 PPO 时，概率比定义为 $r_{i,t}^{\pi}=\pi_{\theta_i}(a_{i,t}\mid o_{i,t})/\pi_{old}(a_{i,t}\mid o_{i,t})$，更新目标为：

$$
L_i^{clip}=\mathbb E\left[\min\left(
r_{i,t}^{\pi}\widehat A_{i,t},
\operatorname{clip}(r_{i,t}^{\pi},1-\epsilon_{clip},1+\epsilon_{clip})\widehat A_{i,t}
\right)\right].
$$

每次更新使用当前行为策略采集的 on-policy 数据，在本批次固定优势与价值目标。UC 的内部控制值与输出层映射记录、消费者的条件边界随行为样本保存，使策略概率计算与采样记录一致。

Actor 的 GAE 与 Critic 回归目标分别计算。半小时实验使用 $\lambda_{GAE}=0.9025$、$\gamma=0.9801$；独立的 `critic_lambda=1.0` 使 Critic 目标为

$$
y_{j,t}^{V}=\sum_{k=0}^{n-1}\gamma^k\widehat R_{j,t+k}
+\gamma^n(1-d_{t+n-1}^{term})
\operatorname{stopgrad}\!\left(V_{j,old}(x_{t+n}^{j})\right).
$$

$n$ 截至本批末尾或第一个真实终止；跨月的批次在真实终止处分段。仅批末截断时保留旧 Value 尾值，真实月末尾值为零。Actor 优势、Critic 目标和行为概率都在采样后固定，本批 Critic 更新不反写 Actor 优势。`critic_lambda<1` 时使用独立的 λ-return 递推，当前小规模协议固定为 1。

Value 输出乘固定尺度后还原奖励单位，UC 尺度为 20、消费者为 10。拟合损失为 $L_j^V=\tfrac12\operatorname{mean}(((V_j-y_j^V)/s_j)^2)$，RMSE 按原奖励单位报告。这是数值尺度，不是训练后的预测校准。多步目标减少对批内中间旧预测的依赖，但目标方差可能增大。

原始 TD 误差、优势和 PPO 截断目标随回报采用元等值尺度；$\gamma,\lambda_{GAE},r_{i,t}^{\pi},\epsilon_{clip}$ 均无量纲。价值平方误差的原始单位为元等值平方，优势或价值目标归一化后的训练量按归一化配置记录。训练损失用于参数更新，费用与奖励的时间换算在环境结算时完成。

### 14.3 外层：生成 UC 候选

内层产生消费者响应策略 $\widehat\pi_C(\pi_U)$。以当前响应采集全体新轨迹，更新全部 Critic，再基于 UC 优势更新 UC Actor 形成策略候选。消费者 Actor 冻结，但仍会对新公告生成不同动作；消费者 Critic 在提案阶段也更新，进入响应分支时恢复公共参考状态。

候选生成提供上层搜索方向，重新训练消费者提供响应后评价。两者使用独立记录，便于判断收益变化来自资源配置还是下层适应。

### 14.4 重新响应与候选接受

定义学习响应下的估计目标：

$$
\widehat W(\pi_U)=\widehat J_U\bigl(\pi_U,\widehat\pi_C(\pi_U)\bigr).
$$

候选集合包含当前 UC 策略。每个候选从同一参考消费者副本开始，采用一致的响应训练预算和匹配的外生验证轨迹，再比较 $\widehat W$、现金、服务和消费者成本。候选接受规则与统计置信区间写入实验协议。

选择后恢复该候选完整响应快照，包括 Actor、Critic、Adam、环境、观测与 RNG；下一批从该分支终点继续。优势归一化仅在批内进行，没有运行中的归一化器。已消耗的全部分支预算和逐批日志编号保留。

### 14.5 下层单边偏离与上层候选改进

固定 UC 和其他消费者，搜索消费者 $i$ 的偏离策略 $\widetilde\pi_i$，定义已发现的改进量：

$$
\widehat\epsilon_i^{NE}=
\left[J_i(\pi_U,\widetilde\pi_i,\pi_{-i})-J_i(\pi_U,\pi_i,\pi_{-i})\right]_+,
\qquad \widehat\epsilon_C^{NE}=\max_i\widehat\epsilon_i^{NE}.
$$

为 UC 候选重新训练消费者并比较：

$$
\widehat\epsilon_U^{SE}=\max_{\widetilde\pi_U\in\mathcal P_{test}}
\left[\widehat W(\widetilde\pi_U)-\widehat W(\pi_U)\right]_+.
$$

正改进给出可利用偏离的直接证据。有限搜索精度由候选集合、优化预算和验证误差描述；报告同时列出这些条件。小规模离散策略例子使用枚举检验，连续模型使用不同搜索强度作对照。

### 14.6 内外层节奏

消费者适应采用较多内层更新，UC 使用较慢的候选更新与响应评价。每轮保存内层预算、候选数量、接受结果及两方改进指标。停止准则联合使用偏离搜索、响应后收益、策略变化和统计区间，阈值以奖励单位和场景规模设置。

### 14.7 双层训练结构伪代码

```python
runner.start(first_training_month)  # 月初初始化；此后只有真实月末换月
for outer_round in range(outer_budget):
    adapt(selected_actors=consumers, update_all_critics=True)
    search_deviations_and_restore()  # 小规模协议预算为零
    common = snapshot_networks_adam_environment_rng()
    candidates = [common.uc]
    candidates += propose_uc_from_fresh_batches(update_all_critics=True)
    branches, scores = [], []
    for candidate in candidates:
        restore(common)             # 相同消费者、环境及随机起点
        restore_uc(candidate)       # 对应 UC Actor / Critic / Adam
        adapt(selected_actors=consumers, update_all_critics=True)
        branches.append(snapshot_networks_adam_environment_rng())
        scores.append(evaluate_on_validation_and_restore())
    selected = select_by_paired_uc_return(scores)
    restore(branches[selected])     # 提交选中响应分支终点
    resolve_batch_log(selected)     # 所有发生过的采样仍计入预算
    search_final_deviations_and_restore()
```

`adapt` 的每一批只采样一次，随后使用固定目标执行 Critic 阶段和选定 Actor 阶段。训练集更新参数，验证集比较候选；当前实验不加载、不评估保留测试集。

### 14.8 当前实现与可复现实验协议

训练实现位于 `RLAlgo/src/raymarl/algorithms/stackelberg/`。`StackelbergConfig` 配置目标、预算和模块；`Stackelberg` 编排一次完整内外层更新；`StackelbergRLModule` 定义策略与价值；`StackelbergTorchLearner` 通过原生 RLlib `LearnerGroup` 更新参数。专用 `StackelbergEnvRunner` 接入原生 `EnvRunnerGroup`，每行经验对应一个完整物理时段。

消费者采用条件 Beta 分布，在单位区间采样后仿射映射到当前物理区间，物理密度扣除区间宽度的对数 Jacobian。削减和移峰的已采样前缀作为后续分布条件，更新时直接使用轨迹中保存的前缀、边界与掩码。零宽维度是确定值，对联合 `log_prob` 的贡献为零。UC 使用第 13.2 节的原始高斯概率。双方 Actor 均使用两层 Tanh 网络，输入固定转换为带符号的 `log1p`；该转换在采集和更新中完全相同。

每个参与者的 Actor 与 Value 有独立 Adam 优化器。消费者 Value 的集中输入按固定顺序拼接 UC 聚合观测和本轮所有消费者的公告后观测，维度为 `(H+20)+N(H+24)`。各户 Actor 只读取本人观测，UC Actor 与 Value 只读取 UC 聚合观测。PPO 每批先固定 GAE、价值目标及行为概率，再按参与者对整批优势归一化一次；价值目标保持元等值尺度。每批先更新全部 Value，再更新本阶段选中的 Actor；冻结网络梯度为 `None`，其参数与 Adam 动量、步数均保持。

Critic 的两层隐藏网络使用 `Linear → LayerNorm → Tanh`，Actor 保持原网络。LayerNorm 按单个状态的隐藏维归一化，无跨批运行统计；UC 不含额外时间支路。固定 Value 单位仍为 UC 20、消费者 10，既有时间观测仍进入普通网络。

采样切片结束时，采集器暂存环境及随机状态，生成下一轮 UC 公告以计算消费者 bootstrap，再恢复该状态。这样下一批在新的策略参数下重新生成公告，队列、SOC 和日历继续承接上一物理时段。真正终止使用零 bootstrap。连续数据不足以构造下一决策时，调用方先显式追加相邻数据。

当前仅保留 Critic LayerNorm 与新增诊断日志；已完整移除供电／现金硬筛选、轮初评价缓存及全拒绝恢复路径。新候选不合格时仍提交候选 0，未采用首批 Critic 保留的讨论方案。供电和现金作为评价指标保留。逐批日志记录固定目标、预测、奖励回报、bootstrap 分布、隐藏层饱和比例及梯度范数。LayerNorm 单项短测与 GRU 文献分析见[当前报告](../../../../experiments/sn_energy_market/LAYERNORM_PILOT.md)。

每轮包含当前 UC 和若干 PPO 更新后的 UC 候选。所有候选从前置消费者适应结束时的公共快照分叉，恢复同一消费者 Actor、Critic、两套 Adam、物理状态和 RNG；对应 UC 参数及 Adam 取自该候选，响应更新次数一致；验证使用相同外生轨迹与随机采样种子。对各候选逐场景计算相对当前 UC 的收益差，以均值和配对标准误构造正态近似区间。默认系数为 1.96，仅当区间下界超过 `min_uc_gain`（默认 0）时接受改进候选；多个候选符合时选择均值最大者，其余情况选择已重新响应的当前 UC。现金、实际服务、失供、DR 和消费者成本随候选一起报告。 当前代码的选择约束只有配对 UC 收益规则，未加入供电率不退化门槛。候选 0 是现有 UC 经重新响应后的分支，并不等于回滚到轮初策略。

有限期评价累计至真正终止，包含一次终端追加项。连续运行或显式截断评价使用同一起点、同一长度窗口内的实际折扣回报作为候选与偏离比较量；带 Critic 尾值的估计单独记录，避免不同候选的价值拟合误差直接改变排序。固定窗口是无限期目标的截断估计，实验通过增加窗口长度检验尾部影响；若单期奖励绝对值上界为 $M$，长度 $L$ 的单策略尾部绝对误差不超过 $\gamma^L M/(1-\gamma)$。训练切片的 GAE 仍使用下一决策时刻的 bootstrap。

消费者单边偏离分别在候选生成前和最终选中策略组上搜索，每次只更新一户，并恢复其余策略和原训练状态。联合停止检查最终策略组的已发现消费者改进、UC 候选改进、Actor 参数均方根变化及配对区间半宽，连续满足 `stopping_patience` 轮后建议停止；外层预算始终给出运行上限。默认阈值分别为 0.1 元等值、0.1 元等值、0.001 和 0.1 元等值，连续轮数为 3，实验可以按场景规模设置。有限搜索与近似区间用于训练诊断，均衡质量由搜索预算和样本精度共同界定。

真实数据采用有限月回合：每月从 1 日零时、明确 SOC 和空任务队列开始；64 步批末和外层轮次结束均不重置，当前策略持续形成月累计用电、SOC、队列和历史反馈，真实月末结算一次后进入下一月份。这里的“连续采样”描述批间保留状态，区别于第 12.1 节的无限期 `episode_mode="continuous"` 目标。

固定预算入口 `batch_critic_pilot.py` 默认运行 3 轮、24 批、1,536 个实际 PPO 采样时段，选定主轨迹前进 768 步。每轮依次为消费者适应 2 批、UC 提案 2 批、候选 0 响应 2 批、候选 1 响应 2 批。每批 64 步，Critic 4 epoch、Actor 2 epoch、minibatch 32；3 轮时每个 Critic 实际执行 192 次优化，回滚后保留步数另记。显式指定 `outer_rounds=72` 时沿用相同逐批预算，共 576 批、36,864 个 PPO 时段、18,432 个主轨迹时段，每个 Critic 实际执行 4,608 次优化。没有额外 MC 预拟合或月中规则暖启动。

`batch_losses.jsonl` 每批立即记录同一固定目标上的 Critic loss／原单位 RMSE 更新前后值，以及实际更新 Actor 的 policy loss；冻结 Actor 留空。批号按实际执行递增，不随候选回滚重置。候选决策另追加分支保留标记，曲线直接使用实际批号：小规模为 1—24，中长期为 1—576，不按 epoch 聚合。完整验证月 MC 只做冻结评价，使用 `finally` 恢复采样状态并核对网络及 Adam 未变。

3 轮基线只推进到训练月第 17 日；已完成的 72 轮主轨迹覆盖完整训练年、12 次真实月末及下一循环的 19 天。验证分别统计 1—10 日、11—20 日和 21 日至月末的原单位 RMSE；供电率与 UC 现金分别报告 48 小时窗口和完整月口径。结果见[小规模对照](../../../../experiments/sn_energy_market/BATCH_CRITIC_PILOT.md)和[72 轮中长期验证](../../../../experiments/sn_energy_market/YEAR_STUDY.md)。逐批 loss 下降不等于验证 RMSE 下降，也不能证明供电保障或均衡收敛。

完整 checkpoint 保存网络、优化器、采集环境、随机状态、进度及停止计数，同时绑定模型、折扣、学习与响应预算、数据切分和场景生成规则。恢复前核对这一训练契约；设备和输出位置属于运行配置。独立 Actor 导出仅包含策略参数与输入规格，可通过同一策略输出接口执行。场景、市场适配和入口位于 `experiments/sn_energy_market/`，算法通过结构化接口调用它们，现有算法和公共训练框架保持独立。运行命令、参数及产物见[训练与评价说明](../../../../experiments/sn_energy_market/TRAINING.md)。

### 17.2 边界与校验

UC 策略输出层依据入期状态生成可行六维行动；消费者 Actor 依据本人状态和本轮公告生成可行四维行动。环境使用同一决策时刻的约束校验提交值。合法行动进入出清，输入错误保留当前状态并返回诊断。市场不足通过服务缺口、任务和成本表示。

UC 公告直接确定本轮容量。消费者阶段读取公告进行分配，原 UC 决策与实际结果通过独立字段追踪。

配置、时序数据和行动在各自入口完成校验；内部市场与结算函数直接使用已校验的数据对象。引擎在提交前统一检查功率、市场成交、任务和资金守恒，避免沿调用链反复判断相同条件。储能边界、个人服务上限、阶段、版本和恢复一致性属于关键检查，继续保留。

### 17.3 分层出清的核心步骤

```python
remaining_der = offer.der_capacity_kw
remaining_uc = offer.uc_capacity_kw
for layer in ("necessary", "early_repayment"):
    requests = build_layer_requests(orders, layer)
    der_preference = build_layer_der_preference(orders, layer, prior_allocations)
    der_initial = allocate_der_pab(der_preference, remaining_der)
    remaining_der -= total(der_initial)
    uc = allocate_uc_pro_rata(subtract(requests, der_initial), remaining_uc)
    remaining_uc -= total(uc)
    der_rescue = allocate_der_pab(
        subtract(requests, der_initial, uc), remaining_der
    )
    remaining_der -= total(der_rescue)
    record_layer(der_initial, uc, der_rescue)
```

第二层偏好扣除必要层已取得的 DER，所有步骤使用同一份价格和公告，按每步实际成交减少剩余容量。

### 17.4 服务、激励和支付接口

服务模块读取实际成交，按原生优先和 FIFO 更新任务。激励模块读取校验后的请求，计算净 DR 与付款。结算模块合并能源电费、补偿、赔偿和外部费用，奖励模块合并经济成本与终端责任。

这种分工使每个数学量有确定的数据来源，也使能量、资金和任务能分别复算。

## 18. Engine 与两阶段适配

### 18.1 单物理期编排

`evaluate_consumer_actions` 按第 17.1 节顺序构造订单、出清、执行物理资源、更新 FIFO、计量 DR 和结算，形成包含奖励、终端和下一状态的 `StateDelta`，再通过 `commit` 唯一提交。执行检查包括原行动保留、来源上限、SOC、任务、支付和终止。

## 22. 可解性、执行性质与经济条件

### 22.1 本地行动域与动态闭合

由式（11）与 $D_i^{due}\le B_i$，有 $p_i^{due}\le\bar p_i^{flex}$ 和 $p_i^{due}\le B_i/\Delta t$。式（13）保证 $\bar p_i^{flex}-p_i^{cut}\ge p_i^{due}$，所以式（14）的负方向区间非空。移出方向按可调整负荷、柔性能力和队列空间共同限制，有限期末关闭新移出。

式（16）使用恒等式 $[x]_+-[-x]_+=x$，将总请求简写为 $p_i^{base}-p_i^{cut}-p_i^{shift}$。又因 $p_i^{serve}\le p_i^{req}=p_i^{native}+[-p_i^{shift}]_+$，式（27）的实际回补自动满足 $p_i^{repay}\le[-p_i^{shift}]_+$。这些简化保持原请求、可行域和队列转移。

任务更新按完成能量逐笔扣除，新任务受队列空间限制，形成余额和截止时间的连续转移。能力超额与服务不足进入 $V_i^{due}$，软期限把违约及后续偿还保留在状态中。

### 22.2 公告、容量与守恒性质

UC 联合域使 $p^{DER,cap},p^{UC,cap}$ 非负，并满足来源和 SOC 边界。市场各层使用剩余容量，跨来源补配使公告容量得到充分利用，形成式（22）的总服务量。

实际使用服从原额度，固定充电保持决策值，主动弃电与未售余量构成实际弃电。式（23）—（26）给出统一的能量平衡。DR 个体补偿求和等于式（18）的全体补偿金额，现金按对手方求和得到完整转账一致性。

### 22.3 固定响应下的服务成本条件

考虑无到期任务、无 DR 采购的单一 PG 情景；固定请求等于冻结基线，公告限供缺口与实际失供量相同，其他成本和未来状态价值固定。每 kWh 的 UC 服务收益率为 $T_i^U-w$，保留供给而发生失供的收益率为 $-\alpha_i-\lambda_n$，二者单位均为元/kWh。对相同正电量比较时，电量因子可以约去，服务收益至少达到限供收益的条件为：

$$
\alpha_i+\lambda_n\ge w-T_i^U.
$$

这个条件划定赔偿发挥作用的参数区域。源价格、储能价值或消费者请求变化时，比较按新的账本重算。第 25 节分别展示高价和重新响应下的结果。

### 22.4 连续削减的响应条件

取无历史任务、刚性负荷为零、柔性能力覆盖基线的单户单期情景，固定带符号移峰为零。公告两池容量及采购上限均为零时，削减子问题的成本由柔性不适与剩余失供净代价组成：

$$
\begin{aligned}
C_i^{total}(p_i^{cut})&=\kappa_i\frac{(p_i^{cut})^2}{p_i^{base}}\Delta t
+(\lambda_i^n-\alpha_i)(p_i^{base}-p_i^{cut})\Delta t,\\
&\quad p_i^{base}\ge\epsilon>0,\quad\kappa_i>0.
\end{aligned}
$$

对这一凸函数求导并应用 $[0,p_i^{base}]$ 边界，得到：

$$
p_i^{cut,BR}=\operatorname{clip}\left(
\frac{(\lambda_i^n-\alpha_i)p_i^{base}}{2\kappa_i},0,p_i^{base}
\right).
$$

该关系揭示供给约束诱导削减的条件：失供净代价越大，调整不适越低，消费者越倾向提前减少原生请求。赔偿基数随剩余请求变化，因此赔偿系数与消费者响应需要联合分析。

这里 $C_i^{total}$ 为本期元等值，最优削减的单位为 kW。正的固定 $\Delta t$ 同时乘在两项成本上，求该子问题的最优功率时约去共同因子；计算实际成本仍使用完整式。

### 22.5 策略层的可解性与研究条件

跟随者博弈由报价排序、同价分配、活动约束、任务和时序状态组成。策略分析围绕响应集合的存在、选择和稳定性开展；PAB 的分段收益需要在相应活动区域处理。

上层分析围绕 $J_U(\pi_U,\pi_C^*(\pi_U))$ 展开，学习过程评价 $\widehat W$ 及偏离搜索。公告容量的执行性质和策略均衡性质分别对应计算层与策略层，证据按第 20.3 节的层次组织。

## 25. 经济激励的适用条件与剩余问题

### 25.1 U01：服务赔偿的成本区间

服务赔偿提高 UC 保留供给并导致原生失供的成本。对固定 1 kWh 请求，UC 单价 0.40、PG 价 0.65、赔偿 1.00 时，服务现金为 −0.25，限供现金为 −1.00，服务的收益较高。

原零考核 N16 在 PG 价 1.70 时，服务现金为 −1.30，限供现金为 −1.00。本轮固定请求条件增加公告供给考核；现金比较保留，主系数 2.00 下，服务奖励为 −1.30，限供奖励为 −3.00；当前生产成对测试已复现。N01 与 N16 作为历史现金对照。未来 SOC、其他来源和消费者响应变化进入进一步的长期比较。

**剩余问题**：现有赔偿对固定请求提供局部激励，完整动态限供行为需要联合成本与响应评价。

### 25.2 U02：完全服务下的来源替代

DER PAB 收入与 UC 零售利润之间的差异提供来源替代动机。N17 中，1 kWh DER 按 0.30 卖出，UC 收益为 0.30；主动弃掉并以 UC 单价 0.90、PG 价 0.20供电，扣除 0.10 弃电成本后，经营收益为 0.60。

服务量相同，UC 收益增加 0.30，消费者支付从 0.30 增至 0.90。这个结果将供应商自利目标与消费者成本的分化直接显现出来。弃电成本、未来储能和费率结构共同决定来源选择。

**剩余问题**：主模型允许这种经济性替代。评价中同时报告来源、弃电、现金和个体成本，政策对照可以研究相应费率或资源条件。

### 25.3 U03：公告供给责任与新增激励审查

U03 的原获利路径是：UC 公告较低供给，消费者为减少失供净损失主动削减，调整后的原生请求与实际失供赔偿基数随之减少。主动削减和实际失供原本已分开计量；本轮修改的是 UC 对供给结果承担的经济责任。

**原算例与新考核对照。** N15 使用单户基线 4 kW、15 分钟、UC 单价 0.40、PG 单价 0.65、完全削减不适 0.75、赔偿 1.00 和消费者失供代价 2.00。消费者候选为削减 0 或 4 kW，UC 供给和采购候选均为 0 或 4 kW，补偿价为 0.50。以下边界对照取 $\lambda_n=0.50$ 元/kWh、服务估值为零：

| 公告与消费者响应 | 消费者成本 | UC 现金 | 新供给考核 | UC 新奖励 |
|---|---:|---:|---:|---:|
| 足够供给、零采购，消费者用电 | 0.40 | −0.25 | 0 | −0.25 |
| 零供给、零采购，消费者完全削减 | 0.75 | 0 | 0.50 | −0.50 |
| 零供给、采购 4 kW，消费者完全削减并取得补偿 | 0.25 | −0.50 | 0 | −0.50 |

旧规则中零供给与完全削减的 UC 收益为 0；新规则保留 1 kWh 供给责任，正常公告在该候选集合中优于无补偿限供。主合成组 $\lambda_n=2.00$ 时，无补偿限供奖励为 −2.00。消费者响应、现金利润与真实失供的定义保持。

**系数与估值联动。** 在无 DER/储能、无到期任务、固定 1 kWh 比较中，服务估值为零时需要 $\lambda_n>w-T_i^U$ 才能使正常供给严格优于上述无补偿限供；有净请求 DR 估值时，相应条件为 $\lambda_n>w-T_i^U+v^{DR}$。边界系数 0.50 配上 $v^{DR}=0.40$，零供给新奖励为 −0.10，仍高于正常供给的 −0.25。主合成组取 2.00，覆盖本组 $w\le1.70,T_i^U\ge0.40,v^{DR}\le0.40$ 的单期比较；储能机会成本和动态响应继续通过场景扫描评价。

**A01：已有减载付费认领。** 固定净减载 4 kW、基线 4 kW、零公告供给，补偿价 0.50、步长 0.25 h、$\lambda_n=2.00$、服务估值为零。采购上限从 0 增到 4，实际 DR 不变，UC 多付 0.50，却少承担 2.00 的供给考核，奖励从 −2.00 增至 −0.50。付费抵扣给已有响应一个真实的经济用途，因此付费采购量与新增减载量必须分列。供给缺口仍为正时，每新增 1 kWh 抵扣的净奖励变化为 $\lambda_n-T^{DR}$；缺口归零后，额外采购继续承担补偿成本。

**A02：到期回补的保守容量预留。** 单户基线 4 kW、能力内到期回补 2 kW，消费者削减 4 并请求回补 2；总请求为 2，净请求 DR 为 2。UC 公告供给 2、实际付费 DR 2，所有请求均完成，但参照 $4+2$ 与抵扣口径产生 $6-2-2=2$ kW 额外缺口，主系数下考核为 1.00 元等值。原因是净请求 DR 已扣除回补，而参照又单独加上到期回补。该方案在此场景保留了额外容量责任。本轮维持已确认的参照与消费者 DR 定义，将其列为未解决的口径问题；修订此项需要统一包含到期回补的参照和 DR 抵扣量。

**A03：容量公告与实际使用。** PG 公告额度本身没有购电成本，额外额度仅在成交时进口。公告满足参照后，继续扩大额度在无新增请求时不改变现金、SOC 或考核；部分状态中 PG 额度因此存在平坦区。评价分别记录公告、实际进口和闲置，不能将额度增加计为真实削峰或真实供电。

**A04：资源、基线与跨期取舍。** 真实物理能力不足时，缺口有不可避免部分；过高基线或较大的到期参照也会提高考核。过高系数会压低充电、资源保留和主动弃电的收益，过低系数则保留限供获利。参数组同时报告物理最大供给、实际请求、供给缺口、现金、任务和初末 SOC，区分资源约束与自主调度。付费抵扣代表本期责任结算，消费者福利改善与 DR 额外性通过正常供给配对场景检验。

**审查结果：** 新规则在已核验的价格与系数范围内消除原 U03 无补偿限供的奖励优势；A01 形成已有减载付费认领的激励，A02 存在额外预留，A03—A04 属于容量、基线及经济参数的适用条件。六维合法行动、一次公告、一次消费者响应与物理执行均保留。当前数值复现见 `tests/test_strategic_audit.py` 与 `tests/test_v9_extended_audit.py`。

### 25.4 U04：基线、反弹与终端价值

净请求减载、PG 削峰和全周期节能对应不同评价对象。基线方法决定请求变化的参照，初末 SOC 决定储能净消耗，事件外回补决定移峰反弹。

实验采用配对外生轨迹、统一初态和终端参数，联合报告这些量。终端估值扫描和连续跨日对照用于检验有限期结果的敏感性。

**剩余问题**：实际基线标定、因果响应识别及终端价值标定构成数据与评价层的研究条件。

### 25.5 U05：均衡与实施条件

策略研究按消费者偏离与 UC 重新响应评价，工程研究按合法概率、阶段经验、真实回合和快照验收。当前环境实现与生产验证为下一阶段的学习与均衡实验提供共同基准。

**剩余问题**：一般策略均衡的存在/选择/收敛、两阶段学习实现、真实数据标定和 UC 资金能力分别需要相应的理论、工程与实证证据。当前账本允许经营亏损，资金约束作为财务扩展设置。

### 25.6 模型公式与机制的简化审查

本轮将 UC 奖励直接写为现金利润减储能、弃电和服务成本，再加已定义的 DR 估值；与原经营收益转写等价。$C^{book}$ 是派生的经营诊断，不是新增状态、动作或优化变量。消费者用两个动作表示削减与带符号移峰，DR 直接按基线减请求计算，补偿直接按总金额和贡献份额结算；这些已落实的等价简化继续保留。

| 模型项 | 审查判断 | 本轮处理 |
|---|---|---|
| UC 奖励经过经营收益中间量 | 可以代数展开 | 已展开；现金与诊断口径保留 |
| 额外 DR 服务估值 $C^{DR,value}$ | 属于可选目标，物理和结算不依赖它；还会增加 U03 系数要求 | 基础经济组固定 $v^{DR}=0$；正值仅作明确的偏好对照。若研究目标只含经营与供给责任，可删除此项，这是目标变更而非等价化简 |
| 基线加到期回补的供给参照 | 与现有净请求 DR 的回补抵扣形成 A02 额外预留 | 标为口径问题，不再增加一层惩罚修补；调整参照或抵扣需联合复核 |
| 现金失供赔偿与公告供给考核 | 分别对应实际损失转账和公告容量责任，输入与收款方向不同 | 各保留一处定义，直接进入对应账本 |
| 待办与逾期成本 | 待办含未到期任务，逾期项增加到期压力；二者不等价 | 保留原设计，避免另加重复期限变量或重复责任项 |
| 两层出清与来源补配 | 必要层保护原生与到期请求，补配利用公告内剩余资源 | 保留原交易规则；删层或删补配会改变分配与策略 |
| 截止桶、实际回补和 FIFO | 分别表达期限分布、已完成电量及任务更新 | 只保留必要状态；请求不作为完成量扣账 |
| 聚合观测与可行输出层 | 前者提供决策信息，后者满足原物理联合域 | 固定参数由配置持有，可派生量不重复加入 UC 输入；不增加市场决策变量 |

公式中的功率、能量、金额、派生诊断和策略参数分别注明用途。能量守恒、容量、SOC、任务与双边资金组成模型闭环；可选估值和偏好系数按研究目标选择。上表区分改变交易行为的删减和保持机制的等价简化。

### 26.2 DR 价值公式的来源与适配

原 PDF 印刷页 5625 的式（13）按本文统一功率与金额记号转写为：

$$
C^{DR,orig}=T^s\frac{(\sum_i p_i^{DR,orig})^2}{p^{DR,target,orig}}
-T^r\sum_i p_i^{DR,orig}.
\tag{30}
$$

这里 $p_i^{DR,orig}$ 对应原论文的单户响应功率，$p^{DR,target,orig}$ 对应原论文的预期响应功率，计算时要求该分母为正。原式分母为一次方；本式保留其代数结构，统一变量记号。原文单价与响应口径按原论文定义引用。

本文的 $p^{DR,cap}$ 表示可补偿采购上限，$p^{DR,net}$ 表示净请求减载，式（7）采用带步长的线性服务估值。式（30）作为文献转写保留原口径；v9 的结算与奖励采用第 2、5、8 节的单位定义。原文按功率定义的效用系数与本文按电量定义的系数，比较时先对齐变量、时间单位及系数尺度。实际金额采用电量乘单价；固定步长下省略共同正因子的优化指标按其定义解释。
