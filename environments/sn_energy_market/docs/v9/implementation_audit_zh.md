## 明确差异

1. **公共日历输入未完成。** §3.2 要求跨日、跨月保留公开日历编码；`observation.build_uc_observation` 和消费者观测首项实际是回合内 `state.period_id`，没有小时相位、星期或月份字段。环境按真实 `state.timestamp` 正确选择价表和月结，但 UC Actor / Value 接收的 H+20 向量没有完整日历。在固定月初零时场景可由 t 推出小时；月份、星期和可变起点的一般日历信息仍不完整。已复现：其余输入相同、分别从 08:45 和 15:45 启动时，当前 UC / 消费者观测逐字段相同，下一时段零售价却分别为 0.60 / 0.40。本次保留观测维度与策略契约。
2. **有限目标的文字与折扣不一致，现已纠正文档。** 原 §10.8 写“不折扣的有限目标”，实际 `batch_critic_pilot.configuration`、`evaluation.GAMMA` 及 §14.8 均为 γ=0.99。全月现金等物理汇总不折扣，候选回报和 MC 标签折扣。终端库存计价正确追加一次，但在 31 天、30 分钟回合月初，其权重为 0.99^1487，约 3.23×10⁻⁷；完整月评价并不能消除该折扣。此次没有调整 γ 或奖励。
3. **异常接口按简洁要求调整。** 原 §10.9 / §17.2 的自动附加失败诊断，原实现通过捕获任意异常并动态附加 `diagnostic` / `residuals` 字段完成。现在保留原异常对象和 traceback，守恒错误直接在消息中给出残差；引擎状态仍不提交失败候选。批量验证程序负责保存输入、快照上下文和失败文件，观测 / 物理记录中的正常诊断字段继续保存。

环境默认 `terminal_energy_value_per_kwh=0`、T=96、H=96；当前 Ausgrid 实验由实验侧设置正库存价值、整月 T 和 H=48。这些是 v9 允许的场景参数，不是通用环境默认值。默认 T=H 会关闭全部新移出；使用移峰场景需让回合覆盖任务期限。§12 的均衡定义、§21 的对比设计和式（30）的原文公式分别属于研究目标、实验设计和文献转写。

## 本次精简

- 删除 `engine._diagnostics` 和六处包装调用，异常不再经过全局捕获和动态属性补丁。
- 删除市场内部重复消费者 ID 检查及 RLlib 适配器的重复消费者行动键检查，由引擎统一构造 / 校验消费者集合。

- 保留阶段、物理可行域、SOC、单户服务上限、守恒、快照和幂等检查；保留机器精度尾差处理。
