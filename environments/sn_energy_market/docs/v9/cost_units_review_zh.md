# v9 成本、奖励与时间单位审查

> 日期：2026-10-14。对象：[完整 v9](modeling_complete_zh.md)与[HTML](modeling_complete_zh.html)。本轮保留主模型、交易顺序、行动维数、FIFO、奖励权重和全部原算例。

## 1. 审查结论

主模型成本与奖励在明确系数单位后量纲一致。全部30组编号公式及其他展示公式的计算关系保持一致，成本收益使用统一C记号，式（4）—（25）先定义成本项再汇总；成本数值和战略取舍保持原值。系数表和计量说明明确UC逐次到期考核与消费者持续逾期成本的区别。

统一计量使用kW、kWh、h、元。主观不适、服务估值、经济成本与奖励以元等值表达，现金账本以实际元表达。按电量计价的功率项乘时间；按持有时长计价的电量存量项乘时间；按次考核、终端估值和已经形成的金额直接计入。

## 2. 全部系数单位

下表定义本模型各系数的单位及计量对象。主观效用系数中的“元”表示元等值，现金单价中的“元”表示实际支付尺度。

| 系数或变量 | 单位 | 计量对象 |
|---|---|---|
| $T_i^U,T^R,b_i^R,\bar b^R,\bar b_i^R,w,T^{DR}$ | 元/kWh | UC 与 DER 电费、PG 采购和 DR 补偿；$T^R$ 为报价底价 |
| $\alpha_i$ | 元/kWh | 原生失供电量的双边赔偿 |
| $k_R$ | 元/kWh | 实际使用的 DER 电量，包括售电和 DER 充电 |
| $k_E$ | 元/kWh | ESS 交流侧充电与放电电量合计的退化估值 |
| $k_a$ | 元/kWh | 实际弃电电量的机会成本 |
| $v^{DR}$ | 元/kWh | 全体净请求减载电量的服务估值 |
| $\lambda_n,\lambda_i^n$ | 元/kWh | UC 公告供给缺口考核、消费者原生失供代价 |
| $\lambda_d$ | 元/kWh，按每次期末考核 | UC 对本期期末到期残留电量的考核；每个物理时段计一次 |
| $\kappa_i$ | 元/kWh | 二次调整功率经基线归一后对应的调整不适 |
| $\lambda_i^B,\lambda_i^{late}$ | 元/(kWh·h) | 待办与到期残留电量在一个时段内的持有成本 |
| $v_E,\lambda_U^{term},\lambda_i^{term}$ | 元/kWh | 有限期结束时的电池存量变化与剩余任务 |
| $C^{ext}$ | 元（本期总额） | 外部模块已经计算完成的本期现金支出 |
| $\epsilon$ | kW | 式（20）功率分母的正下界，与基线功率同量纲 |
| $\chi,\rho_i,\eta_c,\eta_d,\gamma,\lambda_{GAE},\epsilon_{clip}$ | 无量纲 | 事件、比例、效率和训练参数 |

$C^{ext}$ 是金额变量，其物理单位为元；“本期”标明归属时段。$\lambda_d$ 的“每次考核”标明计费事件，区别于带 h 分母的持有成本率。$\epsilon_{clip}$ 是 PPO 的无量纲截断参数，与功率分母下界 $\epsilon$ 分别定义。

### 2.1 成本与收益的统一记号

金额统一写成 $C^{\text{用途}}$，本户金额加下标 $i$。$C$ 同时表示支出和收益，支付方向及在目标中的加减号由具体定义确定；净账单、现金利润与经营收益允许为负。单价和成本系数保留第 2.6 节记号。

| 金额记号 | 含义 | 方向或所属账本 |
|---|---|---|
| $C_i^{energy}$ | 本户 DER 与 UC 总电费 | 消费者支出、UC 收入 |
| $C_i^{DR}$ | 本户获得的 DR 补偿 | UC 支出、消费者收入 |
| $C_i^{comp}$ | 本户获得的原生失供赔偿 | UC 支出、消费者收入 |
| $C_i^{bill}$ | 本户向 UC 的净账单 | 电费减补偿、赔偿；保留净转账方向 |
| $C^{PG}$ | 实际 PG 购电成本 | UC 对外现金支出 |
| $C^{DER,op}$ | 实际 DER 使用成本 | UC 现金运行成本 |
| $C^{ext}$ | 其他本期外部支出 | 已形成的现金金额 |
| $C^{ESS}$ | 储能退化成本 | 按交流侧吞吐估值 |
| $C^{spill}$ | 弃电机会成本 | 按实际弃电估值 |
| $C^{cash}$ | UC 现金利润 | 收入扣除实际现金支出 |
| $C^{book}$ | UC 经营收益 | 现金利润扣除储能退化与弃电成本 |
| $C^{DR,value}$ | DR 服务收益估值 | UC 效用账本 |
| $C^{UC,service}$ | UC 公告供给与到期残留考核 | UC 效用成本 |
| $C_i^{flex},C_i^{service}$ | 本户调整不适、失供与任务持有成本 | 消费者主观成本 |
| $C_i^{total}$ | 连续削减子问题的本期总成本 | 第 22.4 节所定义的局部成本函数 |
| $C^{DR,orig}$ | 原论文 DR 价值公式的转写 | 第 26.2 节文献对照 |

式（4）—（25）先定义各项 $C$ 再汇总，后续直接复用这些金额。强化学习的 $R,J,V,\delta,\widehat A$ 继续表示奖励、长期目标、价值和训练统计。

## 3. 全部成本与奖励的逐项核对

下表按计量依据核对式（18）—（29）及后续目标。现行公式在各自的系数定义下量纲一致，成本收益统一使用 $C$ 记号，计算关系与原算例数值保持一致。

| 项目 / 公式 | 系数与被计量对象 | $\Delta t$ 的处理 | 本期结果 |
|---|---|---|---|
| DER、UC 电费：式（19）两项 | 电量单价 × 成交 kW | 各乘一次，转为 kWh | 元 |
| DR 补偿 $C_i^{DR}$：式（18） | 补偿单价 × 可补偿 kW × 无量纲贡献份额 | 总金额乘一次，份额直接分摊 | 元 |
| 原生赔偿 $C_i^{comp}$：式（19） | $\alpha_i$ × 失供 kW | 乘一次，按失供电量赔偿 | 元 |
| 净账单 $C_i^{bill}$：式（19） | 电费、补偿、赔偿金额 | 直接加减 | 元 |
| PG 采购 $C^{PG}$：式（4） | $w$ × 实际进口 kW | 乘一次，按进口电量计价 | 元 |
| DER 运行 $C^{DER,op}$：式（4） | $k_R$ × 使用的 DER kW | 乘一次，按实际使用电量计价 | 元 |
| 外部支出 $C^{ext}$：式（4） | 已确定的本期金额 | 直接扣除 | 元 |
| 现金利润 $C^{cash}$：式（4） | 已形成的净转账和现金支出 | 直接汇总 | 元 |
| ESS 退化 $C^{ESS}$：式（5） | $k_E$ × 交流侧吞吐 kW | 乘一次，按吞吐电量估值 | 元等值 |
| 弃电机会成本 $C^{spill}$：式（5） | $k_a$ × 实际弃电 kW | 乘一次，按弃电电量估值 | 元等值 |
| DR 服务估值 $C^{DR,value}$：式（7） | $v^{DR}$ × 净请求减载 kW | 乘一次，按减载电量估值 | 元等值 |
| UC 公告供给考核：式（6）第一项 | $\lambda_n$ × 未由公告容量和正价付费 DR 覆盖的缺口 kW | 乘一次，按缺口电量考核 | 元等值 |
| UC 到期考核：式（6）第二项 | $\lambda_d$ × 期末残留 kWh | 每次期末直接计罚 | 元等值 |
| 消费者调整不适：式（20）第一行 | $\kappa_i$ × 归一后二次调整 kW | 乘一次，计入本期时长 | 元等值 |
| 消费者失供代价：式（20） | $\lambda_i^n$ × 原生失供 kW | 乘一次，按失供电量计量 | 元等值 |
| 消费者待办持有：式（20） | 元/(kWh·h) × 期末待办 kWh | 乘一次，计入持有时长 | 元等值 |
| 消费者逾期持续成本：式（20） | 元/(kWh·h) × 期末到期残留 kWh | 乘一次，计入逾期时长 | 元等值 |
| $C^{book},C^{UC,service},C_i^{flex},C_i^{service},R_U,R_i$ | 已形成的金额或元等值 | 在各项内部换算，汇总时直接加减 | 元等值 |
| 电池终端估值：式（29） | $v_E$ × 电池存量变化 kWh | 真正终止时直接计价一次 | 元等值 |
| UC、消费者终端责任：式（29） | 终端系数 × 剩余任务 kWh | 真正终止时直接计价一次 | 元等值 |
| $\widehat R,J_j,V_{\omega_j},\delta_{j,t},\widehat A_{j,t}$ | 奖励、折扣和价值递推 | 奖励已完成时间换算，直接递推 | 元等值 |
| $L_i^{clip},\widehat W,\widehat\epsilon_i^{NE},\widehat\epsilon_C^{NE},\widehat\epsilon_U^{SE}$ | 无量纲概率比或目标差 × 回报 | 直接评价或比较；优势归一化按训练配置另记 | 元等值（原始尺度） |

式（6）的 UC 到期项属于逐次考核，式（20）的消费者等待和逾期项属于持续时间成本。两者保留既定责任设计，分别记录考核次数与持有时长。金额汇总、终端结算和长期回报接收已经换算完成的结果。

## 4. 重点结论与修订位置

| 核对项 | 本轮明确的口径 | 正文位置 |
|---|---|---|
| UC到期考核 | 每个物理时段期末对残留kWh考核一次；系数按次定义，现有式保留 | 2.6、5.2、2.8、19.3 |
| 消费者等待与逾期 | 元/(kWh·h)乘期末余额和本期小时数，沿用期末离散计量 | 2.6、8.4、2.8 |
| 二次不适与分母 | 平方功率除以基线仍为kW；分母下界具有kW单位 | 2.6、8.4、19.2、22.4 |
| 储能退化 | 按交流侧充放电吞吐电量估值，效率用于储能存量更新 | 2.6、5.2 |
| 外部支出 | 接口输入已经换算完成的本期金额；一次性支出按发生时段记录 | 2.6、5.1、19.3 |
| 终端责任 | 元/kWh乘终止时kWh存量，真正终止时追加一次 | 10.8、2.8 |
| 奖励与价值 | 阶段金额直接汇总，折扣回报、TD、优势直接递推 | 9.2、14.5、14.2 |
| 理论比较 | 同电量收益比较和固定步长子问题可约去共同正因子 | 22.3、22.4 |
| 文献转写 | 式（30）保留来源口径，v9费用使用式（18）—（29）的单位 | 26.2 |

UC逐次到期考核随每小时期数变化；消费者持有成本随真实持有时长变化。这是现有两类责任的定义。本轮保留原计费频率，UC 第一项改用公告供给缺口。跨步长实验若要匹配相同的每小时考核强度，需重新标定UC按次系数，并对齐延期、回合时长和折扣。

## 6. 公告供给充足性考核的单位复审

本轮供给参照、两池公告容量和正价付费 DR 抵扣均为 kW，正部差值乘 $\lambda_n$（元/kWh）及 $\Delta t$（h）得到元等值。事件和正补偿价指示量无量纲。到期残留仍为 kWh，乘按次系数直接计罚。

现金电费、DR 补偿和失供赔偿继续按原式结算；新考核属于 UC 效用成本。主贯穿算例新考核为 2.000、UC 奖励为 −1.860，现金 −0.025 与消费者成本保持。当前验证入口为 [verify_v9_u03_revision.py](verify_v9_u03_revision.py)，结果见 [u03_revision_validation.json](u03_revision_validation.json)。
