## 2. 本轮已落实的简化与纠错

### S01 实际放电公式去掉无效的充电项

第3.4节原式在放电最小值中包含 PG 充电。充放电互斥意味着：放电额度大于零时两路充电为零；充电时放电额度为零。因此实际放电可直接写为：

$$
p^{dis,exec}=\min(p^{dis,offer},p^{UC,sold}).
$$

实际 PG 进口仍为 $p^{UC,sold}+p^{ch,PG}-p^{dis,exec}$，这里的 PG 充电项必须保留。该简化依赖当前互斥约束，放开同时充放电后应重新建模。

### S02 UC现金直接复用消费者净账单

第8.4节已经定义 $C_i^{bill}=C_i^{energy}-C_i^{DR}-C_i^{comp}$，第8.5节可直接写为：

$$
C^{cash}=\sum_i C_i^{bill}-wp^{PG,exec}\Delta t
-k_R(p^{DER}-p^{spill})\Delta t-C^{ext}.
$$

这样消费者成本和 UC 收入通过同一净转账字段连接，支付来源和资金对手方保持一致。

### E01 现金成本方向的文字纠正

第8.5节文字原写“净转账合计加外部现金成本”。正确关系为“净转账合计减去外部现金成本”，已与式（24）同步。原公式和数值程序中的成本符号原本正确。

### E02 长期目标中的奖励记号恢复

第10.1节说明中的奖励被误写为 $\widehat p^{DER}$，已恢复为 $\widehat R$。带下标的长期目标公式和 TD 公式原本使用正确的奖励记号，数值奖励未改变。功率使用 $p$，奖励继续使用 $R$。

### S11 UC 一次输出与联合可行输出层

第11.2节用“网络一次输出控制参数 → 策略输出层生成六维可行动作 → 环境校验并公告”统一行动生成。六维动作与原联合约束保持；充电、放电和空闲由最终功率体现，解除三种离散模式和固定采样顺序的要求。

第3.2、11.1、13、16、17节同步策略生成、轨迹和校验说明。随机策略记录内部控制值、物理动作和行为概率，采集与更新使用同一参数化。原物理、交易、消费者和奖励公式保持，具体输出层作为后续策略实现内容。核对见[策略输出层验证](policy_output_validation.json)。

后续五处补齐见[定义核验](definition_completion_validation.json)：第11.2节已给出带符号连续控制、两路充电共同比例及内部概率的固定映射；DR 和价表上限、连续目标与末期回补也已明确。参数化属于策略输出层，式（1）—（30）与六维动作保持，生产实现仍按独立层次验收。

### S03的可读形式

$$
\text{UC奖励}=\text{现金利润}-\text{储能与弃电经济成本}
+\text{DR服务估值}-\text{服务考核}.
$$

主文围绕这条关系解释，现金与非现金项目用表标明。一般公式可以保留在同一节的公式框或附录中，避免同一逻辑多次展开。删除非现金分类会改变收益解释，单纯移到表格不会。

### S04的等价关系

消费者支付中的赔偿为 $C_i^{comp}=\alpha_i p_i^{lost}\Delta t$，服务成本包含 $\lambda_i^n p_i^{lost}\Delta t$，合并后的个人净失供代价使用两者差值。这个合并用于解释决策，不取消实际赔偿记录，也不把 UC 考核与消费者成本合为同一个目标。

### S05的共用流程

“按本层DER意向申购 → 剩余本层请求投入UC → 若仍有缺口且DER有余额，按原报价补配”。必要层使用 $p_i^{nec}$，提前层使用 $p_i^{req}-p_i^{nec}$。两层依次执行同一流程，每一步更新两池剩余容量。补配沿用原DER报价，UC成交使用本户公告电价。

## 4. 有条件的模型或接口简化

### C01 观测容量字段可由已有公告推导

观测中的两池容量由其他公开字段唯一确定：

$$
p^{DER,cap}=p^{DER}-p^{curt}-p^{ch,DER},\qquad
p^{UC,cap}=p^{PG,offer}+p^{dis,offer}-p^{ch,PG}.
$$

在现行冻结输入规则下，删去这两个观测字段不会删除数学信息，维度可由 $H+24$ 降到 $H+22$。但这属于观测schema和网络接口变更，数理信息等价也不保证训练表现相同。本轮仍保留原观测维度和顺序。

在总时域和报价配置固定且已绑定到agent的条件下，$T_{remain}$ 与 $\bar b_i^R$ 也可推导；若参数跨场景变化且未进入其他条件输入，不能直接删去。物理可用放电能力和未来截止桶包含额外状态，不能因当期出清暂时用不到就删除。

### C02 默认零值扩展与主规格分层呈现

基础经济设置中的 $v^{DR}=0$、$\lambda_n=0$、$C^{ext}=0$ 可在主规格中简写，在参数扩展表中保留一般定义。贯穿算例和服务偏好场景使用非零估值，一般模型不能把这些项一概删除。终端价值、储能退化、弃电机会成本和到期责任继续按原场景配置计算。

### C03 FIFO执行表示可按任务性质选择

当前任务是连续电量、同一等待/逾期费率。若只关心余额与期限，同质可分任务可以用截止桶管理，$B_i$ 和 $D_i^{due}$ 由桶求和及读取零号桶计算。若要追踪具体设备任务、不同舒适成本、不可分任务或任务ID履约，保留任务列表。这个选择会改变实现和审计接口，本轮不改任务结构。

## 6. 应继续保留的核心机制

| 内容 | 保留理由 |
|---|---|
| 六维UC与两路充电 | 两类来源改变可售容量、进口现金与未来SOC，合并来源会丢失决策 |
| 公告额度与实际执行 | UC自主资源开放与市场实际使用分别计量，充电和主动弃电保持确定执行 |
| 原生/总请求/必要需求 | 三者分别决定失供、总购电和服务优先级，合并会改变回补分配 |
| 到期预留与软期限 | 防止能力超限形成空行动域，同时保留真实到期债务 |
| 刚性、柔性、队列和设备上限 | 每项都有独立绑定状态，不能只保留一个功率上限 |
| 必要层优先与条件DER补配 | 删除必要层会改变任务优先；删除补配会闲置可供资源并形成额外失供 |
| 请求DR与实际回补分开 | 请求用于减载计量，实际完成用于扣队列，避免缺供生成虚假减载 |
| 净减载、采购上限、正贡献份额 | 分别处理回补抵扣、UC采购决策和个体资金分摊 |
| 现金、经济成本、服务效用 | 资金转移与偏好价值分别核算，简写公式不取消会计分类 |
| 真终止与采样截断 | 决定终端责任和价值bootstrap，合并会改变训练目标 |
| 重新响应与单边偏离 | 支撑Stackelberg–Nash策略评价，单次出清和稳定曲线不能替代 |
| 反例、单位和数据来源 | 解释机制条件与实证范围，压缩重复叙述不删除实际发现 |
