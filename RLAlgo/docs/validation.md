# 原生架构重构验收记录

日期：2026-10-06。库版本：0.2.0。算法基准：Ye 2021 能源论文。

## 本轮已完成的验证

- 完整测试 **46 passed**，包含 CPU 数学验证及 CUDA 历史编码、混合动作反向更新。
- 六种算法分别通过原生 EnvRunnerGroup/LearnerGroup 构建、训练、评估、保存、恢复、Actor 导出和 `from_checkpoint`。
- 固定批次恢复后的模型更新逐项一致；优化器参数所有权互不重叠；非有限 checkpoint 在权重变化前拒绝。
- 验证 MAAC 反事实 baseline、自身屏蔽；SAC 双 Q 与离散策略梯度；MADDPG 梯度边界；PPO 信息隔离与概率密度。
- 原生回合片段跨五步回合采样，联合回放时间身份没有重复；错行数据拒绝进入联合损失。
- 自动 checkpoint 默认保留最新两个，手动保存即使位于同一父目录也不参与自动删除；运行目录互相隔离。
- 静态检查、依赖检查、Git 差异格式检查、wheel/sdist 构建与包内容检查通过。
- 将最终 wheel 安装到独立目录并核对实际导入路径，六种算法均通过训练、评估、恢复和 Actor 导出。

机器可读记录见 [validation.json](validation.json)、[wheel-validation.json](wheel-validation.json) 和 [cleanup.json](cleanup.json)。

## 清理与证据范围

历史输出首次清理删除 **5,837 个文件，14,592,477,901 字节**（约 14.59 GB）。本轮测试、临时安装和构建产物在验收后清理，明细追加在清理记录中。数据集、虚拟环境、运行时、实验脚本、Git 归档和凭据保留。

旧验证记录和已删除的训练曲线不作为 0.2.0 的实验依据。本轮使用小型接口环境，没有重启大型能源实验；不证明论文收益结果、隐私保证、纳什均衡或长期收敛。

新格式 checkpoint 保存模型、目标网络、优化器、回放、RNG 和计数。通用模拟器没有统一的内部状态保存接口，恢复后从新回合继续，不保证重现未完成回合。旧 v0.1 checkpoint 不兼容。
