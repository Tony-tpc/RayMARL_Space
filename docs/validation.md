# 验证记录

## 已完成

- 核心数学、动作概率、参数所有权、联合 Replay、恢复和原生 RLlib 生命周期测试。
- CUDA 历史编码与混合动作的前向/反向更新。
- 原生 CityLearn 3.0.2 的双 venv reset/step/evaluate/close。
- 相同真实初始状态下，固定 Building_1 的动作、改变 Building_2 动作，Building_1 奖励下降且 Building_2 奖励上升，证明收益耦合与利益冲突。

完整测试数量、打包验收、归档提交和实验矩阵状态见同目录机器可读 `validation.json`。

## 证据限制

测试证明对应机制和接口能运行，不证明论文数值结果、隐私保证、纳什均衡或长期收敛。正式实验必须按结果文件和进度状态单独确认；不能把源码存在或任务已启动当作完成。

CPU 必测，CUDA 测试无设备时明确 skip。原生 PPO 出现环境注册和 RLModule 构造弃用提示；测试范围是 RLlib 2.59，不承诺其他版本。
