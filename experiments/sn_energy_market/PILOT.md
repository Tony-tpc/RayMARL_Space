# Ausgrid 小规模训练验证

本入口检查真实数据进入采样、PPO 反向传播、策略更新和验证集评价的完整链路。算法继续使用 `RLAlgo` 中的通用实现；诊断和数据选择位于 `experiments`。

## 数据与预算

固定使用现有 16 户、30 分钟步长、48 步移峰期限。仅加载 `train.npz` 和 `validation.npz`；保留测试集清单元信息，不打开 `test.npz`，不计算测试收益。

训练选择训练年的 7 月、10 月、1 月，分别对应种子 42、45、48；验证选择验证年的 7 月、10 月、1 月和 4 月，分别对应 10042、10045、10048、10051。每个种子仍构造完整月环境，短程采样保持月内状态，未将两日窗口伪装为月末终止。

| 项目 | 本轮设置 |
|---|---|
| 外层轮数 | 3 |
| 采样长度 | 每次 64 个物理时段，即 32 小时 |
| 每轮消费者初始适应 | 2 次更新 |
| 每轮 UC 候选 | 1 个候选，2 次更新 |
| 候选与原策略的消费者重新适应 | 各 2 次更新，预算相同 |
| PPO | 每批 2 个 epoch，minibatch 32 |
| 网络 | 独立 Actor／Value，隐藏宽度 32，CPU 单线程 |
| 折扣与 GAE | 0.9801、0.9025 |
| 验证窗口 | 每个月初 96 步，即 48 小时 |
| 单边偏离搜索 | 本轮关闭，集中检查训练链路 |

主流程共 24 次采样更新、1,536 个物理时段。额外进行消费者单独更新、UC 单独更新各一次，共 128 步；这两次隔离探针随后回滚参数、Adam 状态、环境和随机状态，不保留其训练结果。检查点回放采样另行统计。

验证集用于训练前后比较及 UC 候选选择，不进入梯度批次。评价使用同一组场景和随机种子，比较实际窗口奖励；窗口末状态价值作为独立诊断，不混入候选分数。

## 核查内容

1. 每次采样检查所有数值有限、训练种子身份、物理动作保持、切片截断及行为概率重算。
2. 用显式折扣 TD 求和独立核对 GAE 和价值目标，在 Learner 入口再检查优势归一化。
3. 更新前逐参数核对 Runner 与 Learner 权重相同。
4. 按消费者及 UC 分别记录 Actor、Value 裁剪前后梯度范数和参数变化；冻结模块检查参数与 Adam 状态均不变。
5. 每个执行时段核对物理、队列、账本及奖励，每日抽样对照独立数值参考。
6. 验证评价前后参数不变，并检验检查点恢复后的轨迹逐字段一致。

诊断使用只读梯度和优化器 hook，不修改损失或更新规则。只有当前存在梯度的优化器调用才计入实际优化器步数。float32 原生裁剪与 float64 复算梯度范数采用 `1e-5` 绝对容差；非有限值检查保持严格。

## 复现

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 experiments/sn_energy_market/pilot.py --dataset datasets/ausgrid/processed/manifest.json --output outputs/ausgrid-pilot/reproduce --rounds 3
```

输出包括 `experiment.json`、逐轮结果、`report.json`、逐优化器记录、检查点和 Actor 导出。`report.json` 区分隔离探针、主训练、验证与回放，绑定数据清单和源代码哈希。

通用训练入口也支持保留测试集：

```powershell
.\.venv\Scripts\python.exe -B experiments/sn_energy_market/train.py --dataset datasets/ausgrid/processed/manifest.json --skip-test --validate-data --output outputs/ausgrid-pilot/data-contract
```

`--skip-test` 同时限制文件加载与最终评价路由。算法允许尚未配置测试场景；此时默认测试评价会明确要求调用方指定评价场景。数据集专用逻辑未进入算法。

## 结果解读

`main_training_periods` 是主训练采样量；隔离探针已经从中扣除。`round_N` 的逐步奖励统计同时包含该轮训练和候选验证，纯训练统计取 `diagnostics.samples`，验证对照取 `validation_before`、`validation_after` 和逐轮候选结果。

UC 候选经过真实梯度更新后仍可能被验证集拒绝。因此分别查看候选优化器的参数变化与最终保留策略的变化。短程训练用于判断实现能否正常学习；收益变化仅描述选定月份的两日窗口。

## 2026-10-19 验证结果

本次 3 轮训练通过全部诊断。可追溯摘要为 [pilot_validation.json](pilot_validation.json)，完整记录位于 `outputs/ausgrid-pilot/20261019-verified/`。

| 检查 | 实际结果 |
|---|---|
| 主训练 | 24 次采样更新，1,536 个物理时段 |
| 独立隔离探针 | 2 次更新，128 步，随后回滚 |
| 验证执行 | 3,072 步，含训练前后及候选配对评价 |
| 检查点回放 | 8 步原轨迹与恢复后 8 步逐字段完全一致 |
| 全部受审计执行 | 4,752 个物理时段，76,032 个消费者时段 |
| 梯度与参数 | 34 个网络，2,488 次实际优化器更新，全部有限且非零 |
| 冻结优化器 | 1,048 次参数及 Adam 状态检查通过 |
| 独立奖励／数值参考 | 102 次完整时段对照；逐步奖励账本误差为 0 |
| 数据边界 | 仅加载训练、验证 NPZ；测试场景未配置、未评价 |
| 回归测试 | 289 项通过，6 项训练／CUDA 集成测试未运行；最终诊断修改后另复核 3 项测试 |

行为概率重算最大差为 `2.86e-6`，独立 GAE 最大差为 `1.99e-13`，物理与现金账本最大差为 `3.55e-15`。原始梯度范数最大为 `237.52`；裁剪后的最大范数为 `0.500001287`，符合 0.5 阈值下的 float32 计算容差。

三个 UC 候选均被选中，对应配对平均增益为 `12.03`、`19.09`、`9.05`。最终保留策略的 UC 和全部消费者 Actor／Value 参数均发生变化。

| 四个验证窗口的均值 | 训练前 | 训练后 |
|---|---:|---:|
| UC 折扣回报 | −224.64 | −183.00 |
| 消费者平均折扣回报 | −7.914 | −7.508 |
| 消费者总成本，场景 AUD／窗口 | 302.52 | 288.60 |
| UC 现金利润，场景 AUD／窗口 | −132.13 | −101.97 |
| 原生需求供电率，按请求量加权 | 62.48% | 68.25% |

15 户消费者的验证折扣回报提高，1 户略降。当前策略仍有失供且 UC 现金利润为负；这组结果确认短程更新与评价有效，后续正式实验需要继续检验服务水平、经济表现及跨时段泛化。

首次启动遇到受限环境的 Ray 本机通信问题；随后一次诊断在 64 步隔离探针后因裁剪范数复算容差过严而中止。将诊断容差调整为上述 float32 口径后，从相同随机种子重新完成本次完整运行。生产梯度裁剪未改动，早期中止运行未合入本节的通过数量。
