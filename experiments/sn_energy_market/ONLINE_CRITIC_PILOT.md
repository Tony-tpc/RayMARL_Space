# 全部 Critic 在线更新：一次固定预算实验

日期：2026-10-20。此次只修改算法的梯度更新范围、更新预算与候选状态恢复，不修改 UC 六维动作、Consumer 四维动作、观测、环境物理机制、结算或奖励。主要对照为 `447c8d0` 对应的连续采样第一轮；`3593296` 的第二轮续训只作为累计预算更大的参考。

## 1. 算法修改

旧 `_adapt()` 先筛选参与更新的整个智能体模块，因此冻结 Actor 的同时也冻结了该智能体的 Value。现在每批保留全体数据，依次调用原生 Learner 的两种更新阶段：

1. `critic`：全部 17 个 Value 使用采样时固定的 GAE／λ-return 目标更新；全部 Actor 冻结。
2. `actor`：仅阶段选中的 Actor 使用保存的行为概率及归一化优势更新；全部 Value 冻结。

每批采样时的目标、原始优势与行为概率不因本批 Critic 拟合而重算。新的 Value 随网络同步，在下一批采样的 GAE 与 bootstrap 中生效。未参与损失的参数梯度为 `None`，Adam 不改变其权重、动量或步数；这也适用于已经有优化器历史的网络。更新阶段在异常退出时恢复，不写入 checkpoint。

保留原生 Config／Algorithm／RLModule／Learner／EnvRunner 生命周期、独立 Actor／Value 优化器、固定 Value 单位、梯度裁剪及 checkpoint。`critic_epochs` 纳入配置、命令行和学习契约；更新协议记录为 `all_critics_then_selected_actors_common_consumer_state_v1`，旧机制 checkpoint 被拒绝。

## 2. 候选分支隔离

消费者前置适应后保存公共参考。UC 提案仍按原方式逐次生成，但此时全部 Critic 也会更新。每个候选进入消费者响应前，显式从公共参考恢复消费者 Actor、Value 及各自 Adam，丢弃提案阶段消费者 Critic 的额外进展；保留候选自己的 UC Actor、Value 和 Adam。

响应的环境、观测、随机数状态和预算仍然相同。响应期间更新消费者 Actor 和全部 Critic；评价使用实际窗口回报，不使用 Critic 尾值排序。选定分支的网络、优化器和物理终点一起提交，未选分支回滚。偏离搜索结束后同样恢复完整参考状态。

只加载 `train.npz` 与 `validation.npz`。训练默认月初连续接续、批间保留状态、真实终止重置。本次主轨迹只走过训练年 7 月前 16 天；不据此声称跨季节学习或收敛。

相对同初始化、同 PPO 预算的历史第一轮，UC 全月 RMSE 降低 **10.49%**，月初降低 **44.05%**，平均低估由 8.1596 缩小到 4.0466，解释方差由 -0.2532 升到 0.0723。改善集中在月初；中旬和月末 RMSE 分别增加 4.0236、5.6850，不能据此认定整月各阶段都拟合良好。

16 个 Consumer 中 10 个全月 RMSE 降低，各户 RMSE 的算术平均由 4.7910 降到 4.4473；仍有 9 个 Consumer 解释方差不大于零，说明拟合状态变化的能力仍弱。UC 和 Consumer 的奖励尺度不同，不合并成一个跨智能体 RMSE。

随机策略的 UC 现金收益增加 **1.1146 AUD／48 小时**，但供电率下降 **0.2004 个百分点**；均值动作的现金收益增加 1.1643 AUD，供电率下降 0.0136 个百分点。这次实验支持“在线更新全部 Critic 可以改善此预算下的 UC 总体误差和月初误差”，同时暴露出供电率及月末误差的取舍，不能当作整体策略改进或收敛结论。结果出炉后未调参、未追加训练，测试集未加载或评估。

主轨迹为 `2010-07-01T00:00:00+10:00` → `2010-07-17T00:00:00+10:00`，提交 768 个时段，全部分支预算 1,536 个时段，唯一训练时间戳 768 个。候选选择依次为 1、0、1（0 为现有 UC）。

全部 Value 每网络实际执行 192 次更新；候选回滚后的保留步数如下。执行量与 checkpoint 保留量必须区分。

## 5. 验证与复现

关键检查包括已有 Adam 动量时的 Actor／Value 双向冻结、固定 GAE 目标和行为概率、异常时更新阶段恢复、提案消费者 Value 确实变化后仍恢复相同响应起点、三个候选选择下的精确分支提交，以及训练继续／checkpoint 重放。

共通过 **154 项不重复的 CPU 单元检查和 4 项原生 Ray 集成检查**，修改文件的 Ruff 与 `git diff --check` 通过。一次包含 CUDA 标记的广泛检查在沙箱内触发 Ray 自动初始化超时；本实验及最终算法检查均使用 CPU，不据此声称 GPU 路径通过验证。

本次运行执行了 5,352 次冻结优化器检查，checkpoint 恢复后的 8 步轨迹逐字段精确一致。环境源文件 SHA-256 前后相同；功率、队列、现金残差最大分别为 `7.11e-15`、`5.45e-15`、`3.55e-15`，GAE 残差为 `4.26e-14`，行为对数概率重算残差为 `2.38e-6`。初始／最终验证各含四个完整月份和随机／均值的四个短窗口，验证过程没有优化器更新；8 次真实月末终止来自这两组完整验证。训练主轨迹只运行到 7 月 17 日，真实终止后的重置和 bootstrap 语义由采样器单元检查覆盖，月末结算由市场环境检查覆盖。
