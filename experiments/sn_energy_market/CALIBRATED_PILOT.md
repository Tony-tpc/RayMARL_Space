# Ausgrid 日期覆盖、策略初始化与 Critic 拟合修正

本次完成三项训练侧修正，并运行一次三轮小规模训练。四个固定验证窗口中，随机策略的原生需求供电率达到 **99.93%**，UC 平均现金利润达到 **+33.44 AUD／48 小时**。生产环境源码、六维物理动作、出清、调度执行、费率、设备容量和奖励公式保持原样。

改善主要来自初始策略：训练开始前，新初始化已达到 **99.77%** 和 **+32.52 AUD**；三轮训练进一步改善服务与现金。Critic 的固定训练目标拟合改善，验证状态下仍存在价值高估，具体结果见第 5 节。

## 1. 三项修改

### 1.1 训练日期覆盖

`DatasetEnvFactory` 支持每月 1 日、11 日、21 日、最后一日四种起点。默认训练入口形成 48 个训练场景，先遍历 12 个月，再轮换月内起点，避免短预算一直停留在某个月初。验证与测试的月初场景定义不变。

月中起点从真实月初用固定规则回放构造：UC 使用全部 PG 公告，不主动弃电、不开储能、不采购 DR；消费者不削减、不移峰，先申购 DER 并按底价报价。月累计 UC 电量、历史反馈和日历来自这段实际执行。月末仍按原模型真实终止。回放不作为学习样本，未把月中伪装成零累计电量的月初。

本次固定选择三个训练起点：

| 种子 | 起点 | 起点之前的规则历史 | 到真实月末的 MC 时段 |
|---|---|---:|---:|
| 43 | 2010-07-11 00:00 | 480 | 1,008 |
| 56 | 2010-10-21 00:00 | 960 | 528 |
| 69 | 2011-01-31 00:00 | 1,440 | 48 |

规则历史列表示每个起点包含的历史长度。工厂缓存可在序列化后重新构建，因此这些数目不用于声称规则回放的总执行次数。起点队列为空、SOC 为配置初值是规则构造的结果；进入学习轨迹后，队列与 SOC 正常演化。

### 1.2 策略初始化

实验入口设置 UC 原始六维高斯均值为 `[0.95, 0.02, 0.5, 0.5, 0, 0.5]`，标准差为 `[0.08, 0.05, 0.2, 0.2, 0.1, 0.2]`，初始输出头权重乘 `0.01`。其作用是从较充分的 PG 公告、较少主动弃电和接近空闲的储能控制开始探索，纠正旧初始化导致的大量无必要供给退出。

这些参数只定义初始分布。均值与方差继续参与梯度更新；策略仍通过原有联合可行输出层生成动作，环境接收并执行提交的物理动作。未增加最低供电动作、规则替代或环境自动修正。

### 1.3 Critic 拟合

Value 内部采用固定尺度，UC 为 20、Consumer 为 10：

\[
V_\theta(s)=s_V f_\theta(s),\qquad
L_V=\tfrac12\operatorname{mean}\left[\left(\frac{V_\theta(s)-G}{s_V}\right)^2\right].
\]

`compute_values()` 返回原奖励单位，GAE、bootstrap、实际奖励和候选评价沿用原单位。`value_loss` 是缩放后的优化损失，`value_rmse` 是原单位误差，二者分开报告。

新增 `Learner.fit_values()` 接收固定目标，复用注册的 Value Adam，只更新指定 Value；Actor 参数及其 Adam 不参与。输入张量显式脱离外部梯度图，便于复用。该接口不包含数据集、日期或能源市场逻辑。

本轮先用上述三个训练起点到真实月末的完整轨迹构造 MC 目标，运行 32 个 Value epoch、minibatch 64，再执行 PPO。完整 MC 目标在真实终止处结束，没有人为截断 bootstrap。预热期间 Actor 逐参数保持不变。

通用 `train.py` 接入日期选择、初始化与 Value 尺度；额外 MC 预热由 `calibrated_pilot.py` 显式组织，不隐式增加通用入口预算。

## 2. 数据边界与实际预算

16 户、30 分钟步长、48 步移峰期限、网络宽度 32、CPU 单线程。PG、ESS、队列及费用参数均与旧小规模运行相同；数据资源仍仅由训练年标定。

仅加载 `train.npz` 与 `validation.npz`。测试集文件未读取、未训练、未评价。验证场景为种子 10042、10045、10048、10051，每个窗口从月初运行 96 步；验证同时用于 UC 候选选择，因此属于开发集成绩。

| 工作 | 实际预算 |
|---|---:|
| Value MC 数据 | 1,584 个训练物理时段，全部到真实月末 |
| Value 预热 | 每个 Value 800 次优化，17 个网络合计 13,600 次 |
| 主 PPO | 3 轮、24 次采样批次、1,536 个物理时段 |
| 主流程验证 | 5,376 个时段，含候选选择、随机／均值策略和价值诊断 |
| 检查点回放 | 原轨迹 8 步与恢复后 8 步 |
| 主运行受审计时段 | 8,512 个，含以上采样、验证与回放 |
| 补充冻结价值评估 | 4 个完整验证月、5,904 个时段；不执行梯度更新 |

PPO 预算保持旧运行的三轮、1,536 步；新增 Value 预热有独立采样与计算开销，不能称为相同总计算预算。主运行共记录 15,952 次优化器更新，包含会回滚的候选分支；最终 checkpoint 保留 UC Actor 16 次更新、各 Consumer Actor 48 次更新。

实际 PPO 时间戳并集为 **304 个半小时时段**，MC 并集为 **1,584 个**，合并后仍为 **1,584 个，即 33 天**。第三轮从 1 月最后一天结束后转入 7 月起点，与第一轮有日期重叠。实际运行覆盖三个训练月份；48 个默认场景已经具备全年遍历能力，但本轮没有训练全年。

## 3. 验证集供电率与 UC 收益

下表使用相同四个月初验证窗口。现金和账面利润为每个 48 小时窗口的均值，单位为场景 AUD；UC 折扣回报来自实际奖励，不包含 Critic 尾值。供电率按原生请求电量加权：`1 − 总原生失供电量 / 总原生请求电量`。原生请求已扣除自愿削减和移出，不等于全部基线负荷，也不包含历史任务完成率。

| 策略 | 原生供电率 | UC 现金利润 | UC 账面利润 | UC 折扣回报 |
|---|---:|---:|---:|---:|
| 旧三轮策略，随机动作 | 68.25% | −101.97 | −116.71 | −183.00 |
| 新初始化，尚未训练，随机动作 | 99.77% | +32.52 | +19.76 | +4.76 |

随机动作下，新初始化到训练后的变化为：供电率提高 **0.158 个百分点**，现金利润增加 **0.917 AUD**，UC 折扣回报增加 **2.027**。相对旧训练结果的主要跃升来自初始化纠偏，不能归因于新增三轮训练。

## 4. 代码与环境验证

最终回归 **311 项通过，6 项独立集成／CUDA 用例未运行**，覆盖生产环境、策略分布、采样、GAE、候选评价、Value 独立拟合、日期暖启动和训练集边界。真实 Ray 训练、恢复与导出已由本轮实际运行检验。测试验证月中月累计电量来自真实 UC 成交，月末真正终止，快照缓存互不污染，验证日期保持原样，输入目标图不会被 Value 拟合反向传播。Ruff 和 `git diff --check` 通过。

主运行对每个受审计时段核对动作保持、能量、队列、现金和奖励，并完成 **181 个完整时段**的独立数值参考对照。最大功率残差 `7.11e-15`，现金残差 `3.55e-15`，奖励残差为 `0`，GAE 独立复算残差 `4.26e-14`，行为概率重算差 `2.38e-6`。最大裁剪后梯度范数为 `0.500001114`，处于原有 float32 核查容差内。

检查点恢复后的 8 步轨迹逐字段完全相同。生产环境源码哈希前后相同，Git 差异中没有环境源码、建模公式、费率或资源配置修改。

## 5. Critic 拟合结果与剩余问题

在同一批固定训练 MC 目标上，UC RMSE 从 **34.84 降到 11.55 AUD**，解释方差达到 **0.431**。16 个 Consumer Value 的误差均下降，拟合后范围为 **0.422—2.559 AUD**。这些结果证明尺度与独立拟合路径有效。

验证校准仍存在偏高：四个验证状态的 96 步截断回报诊断 RMSE 从 **13.93 上升到 19.46 AUD**。本次增加完整验证月的冻结回放，单独计算真实终止回报与折扣尾项，结果如下。该评估不执行训练，不把验证回报加入 Value 目标。

| 验证种子 | 最终 Value 预测 | 后续 96 步回报 | 其后折扣尾项 | 至真实月末完整回报 |
|---|---:|---:|---:|---:|
| 10042 | 23.131 | 4.876 | 0.503 | 5.379 |
| 10045 | 32.358 | 14.311 | 0.860 | 15.172 |
| 10048 | 27.549 | 13.024 | 3.602 | 16.626 |
| 10051 | 29.131 | 3.745 | 1.790 | 5.535 |

完整 MC 样本误差 RMSE 为 **17.93 AUD**，表明高估仍然存在，并非只由截断尾项造成。每个状态使用一条冻结随机策略轨迹，完整 MC 是回报样本，不是精确期望值。四个种子的第 96 步 Value 预测及后续 96 步折扣回报与原诊断一致，所有参数保持不变；完整记录见 `value_tail.json`。

训练 MC 来自月中、月末，包含较高月累计电量及较高 UC 阶梯价格；验证检查的是月初第 96 步，消费者仍处第一阶。这一状态分布差异与价值高估相符。它尚未通过单独干预确定为全部误差来源。日期采样接口已经支持月初至月末，当前小规模实际预算尚未平衡所有费率状态。

因此，本轮结论是：**训练侧数值与更新路径已修正，UC 服务和现金改善；Critic 在验证日期上的泛化仍需改进。** 后续应先在既有训练年内平衡月初／月中／月末的价值样本，并独立复查校准，不能把继续拟合同一批中后月回报当作解决方案。本轮到此停止参数更新。

市场模型保留的来源替代、既有减载认领、到期容量责任和公告平坦区未因本次训练被修改。较高供电率不代表这些经济性质消失，也不构成全年盈利或均衡收敛结论。

## 6. 复现与产物

在项目根目录执行固定小规模入口：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 experiments/sn_energy_market/calibrated_pilot.py
```

它写入 `outputs/ausgrid-calibrated-pilot/20261019/`，包含运行契约、MC 拟合记录、三轮结果、完整诊断、逐优化器记录、checkpoint 和 Actor 导出。需重复运行时先指定新的 `OUTPUT` 目录，保留已有结果。

补充冻结价值评估使用同一目录的 checkpoint：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 experiments/sn_energy_market/check_value_tail.py
```

跟踪摘要为 [calibrated_pilot_validation.json](calibrated_pilot_validation.json)。完整运行保留原始文件与哈希，摘要另外绑定最终交付源码：运行过程中只调整过默认 48 场景遍历顺序，当前三个显式训练种子及其日期未变；运行后补充固定输入 `detach()` 和带梯度目标回归检查，当前运行的 NumPy 目标数值路径不变。未拼接其他训练结果。

代码职责仍为：`RLAlgo` 提供通用配置、策略和 Value 拟合；`experiments` 负责日期场景、MC 目标、预算、评价及报告；`environments` 执行既有市场模型。
