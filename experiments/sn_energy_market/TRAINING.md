## 模型与输入

| 项目 | 设置 |
|---|---|
| UC Actor | 原68维；128×128；学习率1e-4 |
| UC Critic | 原68维＋8维因果物理摘要；192×192；学习率1e-3 |
| Consumer Actor / Critic | 原观测及原价值状态；128×128；学习率3e-4 / 1e-3 |
| Critic网络 | 输入变换 → Linear → LayerNorm → Tanh → Linear → LayerNorm → Tanh → Linear |
| UC Critic输入变换 | 时段及剩余时段前两列除以1488，其余74列signed_log1p |
| 其他输入变换 | 沿用原方案，UC Actor保留原SOC模式分支 |
| 新增列初始化 | 第一层最后8列权重为零 |

没有月份独热或GRU。固定1488表示31天半小时时段数，不按月份长度改变；原68维仍包含月内时间，不能称完全没有日历线索。

24/72小时预测的每个未来半小时时段等于上周对应时段与昨日对应时段的平均；第一时段替换成当前已知聚合值。每个窗口输出负荷电量、光伏电量、正刚性缺口电量、最大刚性供需差。缺口为 `(1-dr_limit_ratio)×预测负荷−预测光伏−电网容量`，正式比例0.8，电量乘0.5小时；最大差允许为负。只有聚合负荷/PV历史进入UC Critic，不新增消费者私有信息或未来实际值。

历史可来自前一真实日历月；验证首月可用其之前训练年末的公开聚合历史。数据最开头2010年7月前7天缺历史：缺上周对应时段时用已知昨日对应时段，连昨日也缺则用当前聚合值，不制造历史记录。满7天后使用原公式。保留完整月份及训练预算，单列这336个原点的采样量与bootstrap目标误差。旧离线对照排除了这些原点，冷启动是本次新增、需在线验证的边界行为。

## 采样与学习

四季度同批，每流384步、共1536步；γ=.997，Actor GAE λ=.97，Critic λ=1，Critic2epoch / Actor1epoch，minibatch32，全局梯度裁剪.5。一个新候选，always保留，两个候选各评价两个完整月。种子11，随机权重、空Adam、空回放池、零PopArt历史及四流月初从零初始化。

UC Critic在最近12个保留阶段批均匀无放回选1536条，每个epoch原生随机打乱minibatch，更新次数不增加。首批保持原序且不消耗回放RNG。回放只用于UC Critic；Actor当前批、Consumer Critic新样本。历史内部因果，目标状态可以跨月混合。

Critic目标在采样时固定并以原奖励单位保存。384步片段末端使用下一状态估值bootstrap，真实月末尾值为零、不跨月bootstrap。**离线筛选使用完整月MC及冻结PopArt；此次在线仍用384步bootstrap和在线PopArt，不能将离线成绩视为72轮结果。**

各Critic独立PopArt，β=.99999、标准差下限.1；UC统计只计本阶段1536条新目标，不重复计回放。补偿输出层保持原奖励单位估值；保留Adam参数对象、动量与步数。UC Actor使用采样时保存的 `vf_preds/next_vf_preds` 计算GAE，后续Critic拟合不改变该baseline；Consumer仍使用拟合后的估值重算GAE。整批归一化一次后固定。

生产配置启用 `uc_frozen_gae=True`；设为 `False` 可对照原始拟合后GAE。该开关进入学习契约，恢复时不能混用。冻结的是UC优势所用的估值，不是Critic参数；Critic仍正常训练。这与独立seed 11、24轮实验的算法差异一致，不包含联合return-to-go、完整月采样或独立模式头更新。单种子结果只提供方向性证据。
