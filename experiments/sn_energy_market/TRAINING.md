# V9 always 月份条件 Critic 训练协议

正式实现维护在 `算法实现/双层训练与接口复用`，不合并 main。当前使用混合组 M 的 UC Critic 近期回放，增加公开月份信息。市场、奖励、Actor 观测和 Consumer 私有信息边界保持原样。

## 模型和更新

| 项目 | 设置 |
|---|---|
| UC Actor | 原68维聚合观测；128×128；学习率1e-4 |
| UC Critic | 原68维聚合观测＋12维月份独热编码；192×192；学习率1e-3 |
| Consumer Actor / Critic | 原观测及公共价值状态；128×128；学习率3e-4 / 1e-3 |
| Critic 网络 | signed_log1p → Linear → LayerNorm → Tanh → Linear → LayerNorm → Tanh → Linear |
| 月份 | 按决策时刻的公开日期，1月对应第0列，12月对应第11列；初始月份权重为零 |
| 每阶段采样 | 四季度同批，每流384步，共1536步 |
| 折扣 / GAE | γ=0.997；Actor λ=0.97；Critic λ=1 |
| 学习 | Critic 2 epoch，Actor 1 epoch，minibatch32，梯度裁剪0.5 |
| 候选 | 一个新候选，always保留；两个候选各评价两个完整月 |
| 初始化 | 种子11，随机权重、空Adam、空回放池、零PopArt历史、四流月初 |

UC Critic 对最近12个保留分支的阶段批进行均匀无放回回放，每次仍选1536条，更新次数不增加。首批保持原顺序，不消耗回放随机数。回放只用于 UC Critic；Actor 使用当前采样批，Consumer Critic 使用新样本。所有目标保存为原奖励单位，并固定于采样时；没有完整月MC训练标签。

每个 Critic 分别进行在线 PopArt。UC 的统计只读取本阶段1536条新目标，不能把回放样本重复计数。β=0.99999，标准差下限0.1；更新统计后补偿输出层，保持原奖励单位估值，保留 Adam 参数对象、动量与步数。

Critic 拟合后，用当前批保存的当前/下一价值输入重算 Actor GAE，整批归一化一次后固定。UC 片段末端的下一价值输入同样包含下一决策时刻月份；真实月末尾值为零，不跨月 bootstrap。Actor 不读取月份新增列，也不读取其他消费者的私有状态。

## 分支与恢复

回放池和独立 RNG 随候选分支一起保存、恢复。淘汰候选的回放经验不进入最终保留状态。Learner、Adam、PopArt、四流物理状态、动作 RNG 和回放 RNG 都纳入完整 checkpoint。学习契约包含模型、每个模块的学习率覆盖、回放容量、环境和数据哈希；只恢复完全一致的契约，没有旧版本迁移或兼容入口。

## 运行和比较

```powershell
.\.venv\Scripts\python.exe -B -m experiments.sn_energy_market.run --output D:/Codex/运行目录 --rounds 36
```

运行前需要运行目录下 `verification/ready.json` 证明测试通过、Git 分支与提交正确、工作区干净、源码哈希一致。运行锁和已有状态检查阻止重复启动。每轮保存完整 checkpoint，仅保留最近两份；训练结束导出 Actor，验证磁盘恢复后的精确回放。

当前严格对照为两组各从零36轮。两组都使用相同80维输入层、192×192 UC Critic、M回放和初始权重；对照组只把月份12列固定为零。此屏蔽只存在于 D 盘对照脚本，正式训练入口不提供旧配置开关。

训练后冻结全部参数，在12个完整验证月、每月3个动作种子上评价。时段总数按数据集月历计算，包含闰年。保存 UC/Consumer 收益、原奖励单位价值误差、二月负回报风险状态、月初偏差、Actor/Critic 损失、SOC和充放电。评价前后检查训练状态不变。MC标签不进入训练，测试集不加载。

两组共72轮是计算预算，并非一次72轮训练。相同环境和动作种子用于配对评价，策略不同后轨迹可不同；自身轨迹RMSE同时受访问状态影响，不能仅凭该指标宣称 Critic 或策略收敛。历史128维72轮结果仅作背景，不能用于单独归因月份编码。

所有运行与诊断产物写到 D:/Codex。失败保留现场、完整checkpoint和错误日志，不自动重启或追加预算。只有训练、回放、最终评价和结果核对完成后才写 completed。
